# Minimart POS v3.2.6 — Code Update 01: Barcode Intake

**အခြေအနေ:** ပထမအဆင့် Source Code ပြင်ဆင်မှု။ Release အပြည့်အစုံ မဟုတ်သေးပါ။

## ဒီ Update မှာ ပြင်ထားသည့်အရာများ

1. Stock Receiving ၏ Barcode / SKU input မှ Bluetooth သို့မဟုတ် USB HID Scanner က `Enter` ပို့သည့်အခါ code ကို ရှာဖွေပါမည်။
2. လက်ရှိ Product ၏ Barcode သို့မဟုတ် SKU တစ်ခုခုနှင့် ကိုက်ညီပါက Product အမည်နှင့် Unit ကို အလိုအလျောက်ဖြည့်ပါမည်။
3. Camera Scan နှင့် HID Scan တို့ကို Product lookup တူညီသော helper ဖြင့် လုပ်ဆောင်ပါမည်။
4. SKU ဖြင့် Product ကိုရှာသည့်အခါ ရှိပြီးသား Product Barcode ကို SKU ဖြင့် အစားမထိုးပါ။ ယင်းက Product Barcode နှင့် SKU ကို သီးခြားထားပေးပါသည်။
5. Stock Unit Sticker Registration စာမျက်နှာ၏ စာသားကို လက်ရှိ Code လုပ်ဆောင်ချက်နှင့် ကိုက်ညီအောင် ပြင်ထားပါသည်။ ၎င်းလုပ်ဆောင်ချက်သည် ရှိပြီးသား Stock အတွင်း Unregistered Unit များကို Barcode ဖြင့် မှတ်ပုံတင်ခြင်းသာ ဖြစ်ပြီး Product Stock Qty ကို မတိုးပါ။

## အရေးကြီးသည့် လက်ရှိကန့်သတ်ချက်များ

- ဒီ Update သည် Product-level Barcode / SKU ဖြင့် Stock Receiving ရှာဖွေခြင်းကို ပိုမိုအဆင်ပြေစေသော ပထမအဆင့်ဖြစ်သည်။
- Unit Sticker Barcode ကို POS Sale နှင့် Atomic Cloud Sale Transaction ဖြင့် ချိတ်ဆက်ခြင်း မပါဝင်သေးပါ။
- ZYWELL ZM04 Native Bluetooth Printer Integration မပါဝင်သေးပါ။
- Firebase Production Rules, Cloud Functions သို့မဟုတ် Production Database ကို မပြောင်းလဲထားပါ။
- လက်ရှိ Product, Sales, Stock, Batch, Login, Cashier / Owner Permission နှင့် Cloud Sync Data Model ကို မပြောင်းလဲထားပါ။

## Merge မလုပ်မီ စမ်းသပ်ရန်

1. ရှိပြီးသား Product Barcode ကို Stock Receiving မှ Scan → Enter လုပ်ပြီး Product အမည် / Unit မှန်ကန်ကြောင်းစစ်ပါ။
2. Product တွင် Barcode မတူသော SKU ရှိနေပါက SKU ကို Scan → Enter လုပ်ပြီး Product ရှာတွေ့ကြောင်းစစ်ပါ။
3. SKU ဖြင့် ကုန်ဝင်စာရင်းသိမ်းပြီးနောက် Product ၏ မူရင်း Barcode မပြောင်းကြောင်းစစ်ပါ။
4. မသိသေးသော Barcode ကို Scan လုပ်ပြီး Product အမည် / Unit ဖြည့်ကာ ကုန်ဝင်စာရင်းသိမ်းပါ။ Product အသစ်တွင် Scan လုပ်ထားသော Barcode သိမ်းဆည်းထားကြောင်းစစ်ပါ။
5. Camera Scan၊ manual typing နှင့် barcode မကိုက်ညီမှု warning များကိုစစ်ပါ။
6. Stock Unit Sticker Registration သည် Product Stock Qty ကို မတိုးကြောင်းနှင့် လက်ရှိ unregistered Stock Unit အရေအတွက်ထက် ပိုမမှတ်ပုံတင်နိုင်ကြောင်းစစ်ပါ။

**Release Gate:** Project Full QA နှင့် Manual Stock Receiving / Barcode Regression မအောင်မြင်မချင်း `main` သို့ Merge မလုပ်ပါနှင့်။ Production Firebase ကို Deploy မလုပ်ပါနှင့်။
