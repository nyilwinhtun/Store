## Before Running
1. Export JSON Backup from the current Laptop and Phone.
2. Keep the old `store-mini` Firebase Project unchanged.
3. Follow `NEW-FIREBASE-PROJECT-SETUP-MY.md` to create `businesses/store-mini-main` with the Owner UID.
4. Publish the included full `firestore.rules` file in the new Project.
5. Then run `npm install`, `npm run typecheck`, `npm run build`.

## First Device Only
Use the Laptop/Browser Origin that contains the most complete current local POS data. Close other Minimart tabs and do not connect the Phone to the new Project yet. Sign in with the new Project Owner account and wait for the Auto Sync Safe Bootstrap to finish. Verify branches, products and sales in Firestore before proceeding to the second device.

## Cashier
Use the Cashier UID from `minimart-production` → Authentication → Users. Do not use the old `store-mini` Cashier UID. After Branch data is visible to the Owner, link the new Auth account via Profile → ဝန်ထမ်းအကောင့် / Branch Permission → `ရှိပြီးသား Account ချိတ်ရန်`.

## Important
The new Firebase Project has empty Firestore. The first Owner device may upload its existing local POS records as the initial safe bootstrap. A conflict is a stop condition: do not Reset Local Data or upload again. Preserve backups and inspect the conflicting records first.
