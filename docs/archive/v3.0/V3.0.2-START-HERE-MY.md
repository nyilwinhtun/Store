# v3.0.2 စတင်အသုံးပြုနည်း

1. လက်ရှိ v3.0.1 Project နဲ့ Firebase Data ကို Backup လုပ်ပါ။
2. v3.0.2 ZIP ကို Folder အသစ်အဖြစ် ဖြည်ပါ။
3. မိမိ Project မှာသုံးနေတဲ့ `.env` ကို လိုအပ်သလို ပြန်ထည့်ပါ။ Firebase Config ကို ပြန်စစ်ပါ။ ဒီ Upgrade မှာ Firebase Project/Rules မပြောင်းထားပါ။
4. Terminal မှာ `npm install` လုပ်ပါ။
5. `npm run typecheck` နဲ့ `npm run build` ကို အောင်မြင်ကြောင်း စစ်ပါ။
6. Localhost မှာ အရင်စမ်းပြီးမှ Deploy လုပ်ပါ။

## ပထမဆုံး စမ်းသပ်ရန်

- Source Branch နဲ့ Destination Branch မတူကြောင်း စစ်ပါ။
- Product ရဲ့ Product Stock နဲ့ Batch ပို့နိုင်ပမာဏကို နှိုင်းယှဉ်ပါ။
- Batch over-coverage ရှိရင် အကြောင်းကြားချက်ကို ဖတ်ပြီး အတည်ပြုပါ။
- Expired Batch ပမာဏကို Shipment ထဲ မထည့်နိုင်ကြောင်း စစ်ပါ။
- Shipment အောင်မြင်ရင် Source Stock တစ်ကြိမ်သာ လျှော့ကြောင်း စစ်ပါ။
- Shipment မအောင်မြင်ရင် Source Stock မပြောင်းကြောင်း စစ်ပါ။
- Receiver Confirm ပြီး Owner Approval မလုပ်မချင်း Destination Stock မတိုးကြောင်း စစ်ပါ။

**သတိ:** Batch over-coverage Warning ပြပြီး Shipment အောင်မြင်လျှင် Audit Log ထဲ `STOCK_SHIPMENT_BATCH_WARNING` ကို စစ်ပါ။ Batch ledger က Product Stock ထက်ပိုနေသည့် အချက်ကို နောက်ပိုင်း Stock Reconciliation အဆင့်တွင် သီးခြားပြင်ရန်လိုနိုင်သည်။
