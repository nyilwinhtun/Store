# Minimart v3.0.2 — Branch Shipment Batch Validation Fix

## ပြင်ဆင်ရသည့်အကြောင်းရင်း

v3.0.1 ရဲ့ Branch Shipment Dispatch မှာ `trackedTotal > product.stock` ဖြစ်တာနဲ့ Shipment ကို တန်းပယ်ချထားပါတယ်။ ဒါပေမဲ့ လက်ရှိ Stock Transfer Flow ကတော့ အဲဒီလို legacy Batch over-coverage ရှိရင် Product Stock ကို အမှန်တကယ်လက်ကျန်အဖြစ် သတ်မှတ်ပြီး ပို့နိုင်တဲ့ Expiry Batch ပမာဏအတွင်း လုပ်ဆောင်ခွင့်ပေးကာ Audit Warning ထည့်ထားပြီးသားဖြစ်ပါတယ်။ Shipment Flow နဲ့ Transfer Flow မတူညီနေတဲ့အတွက် Product Stock မှာ ပစ္စည်းလုံလောက်နေသော်လည်း Shipment မပို့နိုင်တဲ့အခြေအနေ ဖြစ်နိုင်ပါတယ်။

## v3.0.2 ပြင်ဆင်ချက်

1. Branch Shipment ကို Stock Transfer ရဲ့ Batch-over-coverage policy နဲ့ ကိုက်ညီအောင် ပြင်ထားသည်။
2. Product Stock ကို authoritative balance အဖြစ်ထားပြီး Batch စုစုပေါင်းက Product Stock ထက်ပိုနေပါက Shipment ကို အလိုအလျောက်မပိတ်တော့ပါ။ ပို့ပြီးပါက `STOCK_SHIPMENT_BATCH_WARNING` Audit Record ထည့်သည်။ Batch ကွာဟချက်ကို နောက်မှ ပြန်စစ်ရမည်။
3. သက်တမ်းကုန် Batch ကို ပို့ခွင့်မပြုပါ။ မပို့နိုင်သည့်အခါ ပစ္စည်းအမည်၊ Product Stock၊ ပို့နိုင်သေးသော Batch ပမာဏနှင့် Expired Batch ပမာဏကို သီးခြားပြသည်။
4. Shipment Form မှာ Product တစ်ခုချင်းစီအတွက် `Batch ပို့နိုင်` ပမာဏကို ပြသည်။
5. Source Branch / Destination Branch / Product / Quantity / concurrent stock change Error များကို သီးခြားမြန်မာစာ Message ပြသည်။
6. Shipment မအောင်မြင်ပါက working-copy validation မပြီးမချင်း Zustand Stock ကို မပြောင်းပါ။
7. Multi-item Shipment တစ်ခုမှာ over-coverage သတိပေးချက်များကို တစ်ကြိမ်တည်းပြသည်။

## မပြောင်းထားသောအရာများ

- Firebase Project Config (`minimart-production`)
- Business ID (`store-mini-main`)
- Firebase Authentication / Owner UID / Cashier UID
- Firestore Rules
- Stock Receiver Permission နှင့် Owner Approval Flow
- Cashier Sales / Mobile POS / Barcode
- Existing Product, Sales, Stock Transfer, Stock Shipment data schema

## စမ်းသပ်မှုအခြေအနေ

Source-level ပြင်ဆင်မှု ပြီးပါပြီ။ TS/TSX Syntax Check ကို စစ်ဆေးရမည်။ `npm install` သည် ယခု environment တွင် timeout ဖြစ်သောကြောင့် Full Typecheck / Production Build နှင့် Firebase Live Test ကို အတည်ပြုမထားပါ။ အသုံးမပြုမီ local machine တွင် `npm install`, `npm run typecheck`, `npm run build` ပြီးစေပါ။
