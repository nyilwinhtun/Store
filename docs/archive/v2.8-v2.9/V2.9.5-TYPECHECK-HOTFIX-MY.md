# Minimart v2.9.5 Typecheck Hotfix

## ပြင်ထားသည့်အချက်

`src/components/CloudSyncPanel.tsx` ထဲတွင် `errorMessage(error)` helper ကို ကြေညာထားသော်လည်း ဘယ်နေရာမှာမှ အသုံးမပြုထားပါ။ `tsconfig.json` တွင် `noUnusedLocals: true` ဖြစ်နေသောကြောင့် TypeScript က `TS6133` error ထုတ်ခဲ့သည်။

ဒီ Hotfix မှာ အသုံးမပြုထားတဲ့ helper function တစ်ခုတည်းကို ဖယ်ရှားထားသည်။ Firebase configuration, Authentication, Firestore Rules, Cloud Sync behavior, LocalStorage/Data structure တို့ကို မပြောင်းထားပါ။

## Update လုပ်နည်း

1. လက်ရှိ Project ကို Backup လုပ်ပါ။
2. ဒီ ZIP ကို folder အသစ်တစ်ခုထဲ ဖြည်ပါ၊ သို့မဟုတ် လက်ရှိ Project ထဲက `src/components/CloudSyncPanel.tsx` ကို ZIP ထဲက ဖိုင်နဲ့ အစားထိုးပါ။
3. Terminal မှာ `npm install` ပြီးလျှင် `npm run typecheck` ကို ပြန်လုပ်ပါ။
4. Typecheck အောင်မြင်မှ `npm run build` ကို ဆက်လုပ်ပါ။

မှတ်ချက်: ဒီ Hotfix ကို ပြင်ဆင်စဉ် dependency download timeout ဖြစ်ခဲ့သဖြင့် Full TypeScript Build ကို ဒီပတ်ဝန်းကျင်မှာ အတည်မပြုနိုင်ခဲ့ပါ။ ဒီ Hotfix က Screenshot ထဲက `TS6133: 'errorMessage' is declared but its value is never read` error ကို တိုက်ရိုက်ဖြေရှင်းပေးသည်။ နောက်ထပ် diagnostic ပေါ်လာပါက အဲဒီအမှားကို သီးခြားစစ်ဆေးရမည်။
