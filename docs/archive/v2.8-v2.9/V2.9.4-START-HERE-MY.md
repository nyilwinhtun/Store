# v2.9.4 စတင်အသုံးပြုရန်

## Update လုပ်မီ

- Owner Laptop နဲ့ Phone နှစ်ခုလုံးမှာ JSON Backup ထုတ်ပါ။
- လက်ရှိ Firebase Configuration နဲ့ `.env` ကို မဖျက်ပါနဲ့။
- Firestore Rules ကို မစစ်ဘဲ အစားမထိုးပါနဲ့။

## Login လုပ်ရန် တစ်နေရာတည်း

1. App မှ Profile ကို ဖွင့်ပါ။
2. `Firebase Business Account` အပိုင်းသို့ သွားပါ။
3. Owner သို့မဟုတ် Cashier Email / Password ဖြင့် Login ဝင်ပါ။
4. Role နဲ့ Member Document အလိုက် Owner Workspace သို့မဟုတ် Limited Cashier POS ကို အလိုအလျောက် စစ်ဆေးပေးပါမယ်။

Settings → Business Cloud Sync မှာ Login Form သီးခြားမရှိတော့ပါ။ အဲဒီနေရာက Profile Login ကိုဖွင့်ပေးပါတယ်။ Cloud Sync panel ကနေ Sign Out မလုပ်တော့ပါ။ App Account Sign Out ကို Profile ထဲကနေသာ လုပ်ပါ။

## Cashier Access မရပါက

Owner Account နဲ့ Profile → ဝန်ထမ်းအကောင့် / Branch Permission ကိုဖွင့်ပါ။ Cashier row မှာ Document UID နဲ့ Member Path ကို Copy လုပ်ပြီး Verify ခလုတ်နှိပ်ပါ။ Firebase Authentication UID, Document ID, Document ရဲ့ `uid` field, Email, Role, Status နဲ့ Branch ID တို့ တစ်ခုချင်း ကိုက်ညီရပါမယ်။

## Mobile POS

ဖုန်းမှာ POS ဖွင့်ပြီး Product အပေါ်ပိုင်းနဲ့ Cart အောက်ပိုင်းကို သီးခြား Scroll လုပ်ပါ။ Checkout Button ဟာ Cart Pane ရဲ့ အောက်ခြေမှာ မြင်ရရပါမယ်။ Screen height နည်းလွန်းခြင်း သို့မဟုတ် keyboard ပွင့်နေခြင်းကြောင့် layout မမှန်ပါက screenshot ပို့ပေးပါ။

## Printer

Laptop / Mac မှာ Browser Print ကို ဆက်သုံးပါ။ ZM04 Android Direct Bluetooth ကို ဒီ Version မှာ မပါသေးပါ။ အဲဒီအပိုင်းအတွက် သီးခြား Android Native SDK integration လိုအပ်ပါတယ်။

## Build

```bash
npm install
npm run typecheck
npm run build
npm run dev -- --host --port 5173 --strictPort
```

`npm run build` အောင်မြင်မှ GitHub ကို Deploy လုပ်ပါ။
