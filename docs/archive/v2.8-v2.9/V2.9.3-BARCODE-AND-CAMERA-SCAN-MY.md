# Minimart v2.9.3 — Barcode, Bluetooth HID နှင့် Phone Camera Scan

ဒီ Version သည် v2.9.2 Checkout Item Details ကို ဆက်ထိန်းထားပြီး Product Registration, ရိုးရှင်းသော ကုန်ရောက်စာရင်းနှင့် POS Checkout တို့တွင် Barcode အသုံးပြုနိုင်ရန် ထည့်သွင်းထားသည်။

## ပါဝင်သည့်အချက်များ

- Product ထည့်/ပြင်ရာတွင် `SKU / Product Code` နှင့် `Barcode` ကို သီးခြားသိမ်းသည်။ အရင် Product များတွင် Barcode မရှိလည်း ဆက်အသုံးပြုနိုင်သည်။
- Product ရှာဖွေမှုတွင် အမည်၊ SKU နှင့် Barcode သုံးမျိုးလုံးဖြင့် ရှာနိုင်သည်။
- POS Search Box ကို Focus လုပ်ထားပြီး Bluetooth HID Scanner ဖြင့် ဖတ်လျှင် Scanner က Keyboard အဖြစ် Barcode စာသားထည့်ပေးသည်။ Scanner ကို `Enter` suffix ပို့ရန် configure လုပ်ထားပါက Product ကို Cart ထဲသို့ အလိုအလျောက် ထည့်မည်။
- POS မှာ တစ်ပစ္စည်းကို ထပ် Scan ဖတ်လျှင် လက်ရှိ Cart Quantity တိုးသည်။ Stock၊ Expiry၊ ရောင်းဈေးနှင့် Quantity validation များသည် မူလ `addToCart` လုပ်ဆောင်ချက်မှ ဆက်လက်စစ်ဆေးသည်။
- Unknown Barcode ဖြစ်လျှင် Product မဖန်တီးဘဲ မတွေ့ကြောင်း အသိပေးသည်။ Owner က Inventory မှာ Barcode အသစ်သတ်မှတ်ပြီး Product ကို Save လုပ်နိုင်သည်။
- Inventory Product Form နှင့် ကုန်ရောက်လက်ခံရေးမှာ Phone Camera Scan ခလုတ် ထည့်ထားသည်။
- ကုန်ရောက်စာရင်းမှာ သိပြီးသား Barcode ကို Scan လုပ်လျှင် Product အမည်/Unit ကို အလိုအလျောက်ဖြည့်နိုင်သည်။ မသိသေးသော Barcode ဆိုလျှင် အမည်ဖြည့်ပြီး Product အသစ်အဖြစ် လက်ခံနိုင်သည်။
- Barcode နှင့် SKU တို့သည် လက်ရှိ Branch အတွင်း တစ်ခုနှင့်တစ်ခု မထပ်စေရန် စစ်ဆေးသည်။ Branch မတူလျှင် Branch တစ်ခုချင်းစီအလိုက် သီးခြားအသုံးပြုနိုင်သည်။
- Product Cloud Sync record payload ထဲတွင် `barcode` field ပါဝင်သည်။ ရှိပြီးသား Product ID, SKU, Stock, Branch ID နှင့် LocalStorage schema ကို မပြောင်းထားပါ။
- Service Worker cache version ကို v2.9.3 သို့ တိုးထားသည်။

## Bluetooth Scanner အသုံးပြုနည်း

ဒီ Version သည် Browser ထဲမှ Bluetooth radio ကို တိုက်ရိုက် pair လုပ်သည့် Web Bluetooth implementation မဟုတ်ပါ။ Bluetooth Scanner ကို ဖုန်း/ကွန်ပျူတာ၏ Bluetooth Settings မှာ Pair လုပ်ပြီး `HID Keyboard` သို့မဟုတ် `Bluetooth Keyboard` mode ဖြင့် အသုံးပြုသည်။

1. Scanner model သည် HID Keyboard mode ကို support လုပ်ကြောင်း စစ်ပါ။
2. Device Bluetooth Settings မှာ Scanner ကို Pair လုပ်ပါ။
3. Scanner configuration manual အတိုင်း suffix ကို `Enter` သတ်မှတ်ပါ။
4. POS Search Box သို့မဟုတ် Product/Receiving Barcode Field ကို တစ်ချက်နှိပ်၍ Focus လုပ်ပါ။
5. Barcode ဖတ်ပါ။ POS Search Box တွင် Enter ရောက်လျှင် Product ကို Cart ထဲထည့်မည်။ Receiving/Product Form တွင် Barcode ကို ဖြည့်ထားပေးမည်။
6. Scanner က Enter suffix မပို့နိုင်ပါက POS မှာ Barcode ကိုရိုက်ပြီး Enter နှိပ်နိုင်သည်။

Scanner တိုင်း၏ Pairing နဲ့ suffix ပြင်ဆင်နည်း မတူသောကြောင့် Hardware Model မသိရသေးခင် တိုက်ရိုက်စမ်းသပ်အောင်မြင်သည်ဟု မသတ်မှတ်ထားပါ။

## Phone Camera Scan

- Camera Scanner သည် `@zxing/browser` နှင့် `@zxing/library` ကို အသုံးပြုသည်။ EAN-13/EAN-8, UPC-A/UPC-E, Code 128, Code 39, ITF နှင့် အခြား supported 1D/2D formats များကို decode လုပ်နိုင်သည်။
- Camera သုံးရန် Browser မှ Permission Allow လုပ်ရမည်။ GitHub Pages ကဲ့သို့ HTTPS site သို့မဟုတ် `localhost` တွင် ဖွင့်ပါ။ Plain HTTP IP address မှာ Camera Permission မရနိုင်ပါ။
- ဖုန်းနောက်ကင်မရာကို Browser/Device က ပေးသည့် camera list အလိုက် အသုံးပြုမည်။ Device တချို့တွင် camera permission သို့မဟုတ် camera hardware ရရှိမှုကွာနိုင်သည်။

## Barcode အချက်အလက်နှင့် Data Safety

- `barcode` သည် Optional Field ဖြစ်သည်။ အရင် Data တွင် field မရှိပါကလည်း အလုပ်လုပ်မည်။
- အရင် Product SKU ကို Barcode Field အဖြစ် အလိုအလျောက် ပြောင်းမထားပါ။ သို့သော် POS Scan/Lookup က Barcode သို့မဟုတ် legacy SKU နှစ်မျိုးလုံးကို ရှာနိုင်သည်။
- Barcode သည် Leading Zero များကို ထိန်းသိမ်းသည်။ Scan input ကို Trim လုပ်ပြီး whitespace ဖယ်ကာ uppercase ပြောင်းသည်။
- Owner/Cashier Role, Firebase Login, Firestore Rules, Cloud Sync architecture, POS Checkout, Stock Transfer နှင့် v2.9.2 Receipt Detail logic ကို မပြောင်းထားပါ။ Product record သည် Cloud Sync မှာ အရင်အတိုင်း record payload အပြည့်ဖြင့် Sync လုပ်သည်။
- Firestore Rules အသစ် ထည့်ရန် မလိုပါ။ သို့သော် လက်ရှိ Owner Product Write permission ကို မိမိ Firebase Project Rules ထဲတွင် ရှိနေဆဲဖြစ်ကြောင်း စစ်ဆေးပါ။
- Bluetooth/Cam scan မှ ထည့်ထားသည့် Product ကို Save/Checkout မလုပ်ခင် အမည်၊ Unit၊ Price၊ Branch ကို ပြန်စစ်ပါ။

## Update နှင့် စမ်းသပ်နည်း

1. Owner Device တစ်ခုချင်းစီတွင် JSON Backup ထုတ်ပါ။ LocalStorage/IndexedDB ကို မရှင်းပါနှင့်။
2. ZIP ကို Folder အသစ်အဖြစ် ဖြည်ပြီး VS Code မှ ဖွင့်ပါ။ လက်ရှိ `.env` ကို လုံခြုံစွာ ပြန်ထည့်ပါ။
3. Terminal တွင် `npm install` လုပ်ပါ။ ZXing camera package အသစ်များ ထည့်ထားသောကြောင့် ဒီအဆင့် လိုအပ်သည်။
4. `npm run typecheck` နှင့် `npm run build` နှစ်ခုလုံး အောင်မြင်ကြောင်း စစ်ပါ။
5. `npm run dev -- --host --port 5173 --strictPort` ဖြင့် Local စမ်းပါ။
6. အရင် Product တစ်ခုကို Barcode ထည့်ပြီး Save လုပ်ပါ။ အရင် SKU နဲ့လည်း ဆက်ရှာနိုင်ကြောင်း စစ်ပါ။
7. Test Bluetooth HID Scanner မရှိသေးလျှင် keyboard နဲ့ Barcode စာသားရိုက်ပြီး Enter နှိပ်၍ POS Flow စမ်းပါ။
8. Phone မှ HTTPS Deployment ကိုဖွင့်၊ Camera Permission Allow လုပ်ပြီး Product Form, Receiving Form နှင့် POS တို့မှာ Scan စမ်းပါ။
9. Branch နှစ်ခုအတွက် Barcode duplicate behavior, Phone/Laptop Cloud Sync, Sale/Stock validation ကို စမ်းပါ။
10. Test ပြီးမှ GitHub ကို Push/Deploy လုပ်ပါ။

## စမ်းသပ်မှုကန့်သတ်ချက်

ဒီအလုပ်လုပ်သည့် Environment မှာ npm dependency install timeout ဖြစ်သောကြောင့် Full `npm run typecheck`, `npm run build`, Bluetooth Hardware Test နှင့် Phone Camera Live Test မလုပ်နိုင်သေးပါ။ 21 TS/TSX source files ၏ syntax transpile စစ်ဆေးမှုနှင့် `package.json`/PWA manifest JSON စစ်ဆေးမှုကို အောင်မြင်ထားသည်။ Hardware compatibility ကို Scanner Model ရရှိပြီးမှ အတည်ပြုရမည်။
