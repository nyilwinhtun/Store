# Minimart v2.9.1 — Receipt Print Choice & Printer Test

## ဒီ Version မှာ ပြင်ထားတာ

1. Checkout ပြီးတာနဲ့ Sale ကို အရင် Local POS Store ထဲ သိမ်းပြီးမှ Result Modal ပြသည်။ Print ရွေးမရွေးကြောင့် Sale/Stock Save ပျက်မသွားပါ။
2. `Printer နဲ့ Receipt ထုတ်မယ်` ရွေးလျှင် Browser/System Print Dialog ဖွင့်သည်။
3. `မထုတ်တော့ဘူး · ပမာဏပဲကြည့်မယ်` ရွေးလျှင် Receipt မထုတ်ဘဲ Customer ကို စုစုပေါင်းကျသင့်ငွေ ပြနိုင်သော Amount-only Screen ဆက်ပြသည်။ `ပြီးပါပြီ` နှိပ်မှ ပိတ်သည်။
4. POS မှာ 58mm / 80mm Paper Width ရွေးချယ်နိုင်သည်။ ဒီ setting ကို Device တစ်ခုချင်းစီရဲ့ LocalStorage ထဲမှာပဲ သိမ်းသည်။
5. POS နဲ့ Settings နှစ်နေရာလုံးမှာ Test Print ပါသည်။ Test Slip မှာ မြန်မာစာ၊ စုစုပေါင်း၊ စက္ကူအကျယ်ကို စစ်ကြည့်နိုင်သည်။
6. Sales History မှ ယခင် Voucher ကို Print ထုတ်နိုင်သည့် လုပ်ဆောင်ချက်ကို ဆက်ထိန်းထားသည်။

## Bluetooth Printer အခြေအနေ — အရေးကြီး

v2.9.0 Source ထဲမှာ Direct Bluetooth Pairing / ESC-POS Bluetooth transport code မရှိပါ။ Sales History မှာ Browser `window.print()` သာ အသုံးပြုထားသည်။ v2.9.1 ကလည်း လက်ရှိအဆင့်တွင် Browser/System Print နည်းလမ်းကို စီမံပေးခြင်းသာ ဖြစ်ပြီး App အတွင်းကနေ Bluetooth printer ကို တိုက်ရိုက် scan/pair လုပ်ပေးသည့် implementation မဟုတ်ပါ။

- Android: Bluetooth printer ကို Android Print Service က expose လုပ်ပေးထားမှ Chrome Print Dialog ထဲမှာ ရွေးနိုင်သည်။ Bluetooth Classic thermal printer အများစုအတွက် manufacturer သို့မဟုတ် သင့်တော်သော third-party Print Service လိုနိုင်သည်။
- macOS/Windows: OS မှာ printer driver သို့မဟုတ် print service အဖြစ် ထည့်ပြီး Chrome Print Dialog ထဲမှာ ပေါ်လာမှ အသုံးပြုနိုင်သည်။
- iPhone/iPad: Browser မှ AirPrint အသုံးပြုရာတွင် AirPrint-compatible printer (ပုံမှန်အားဖြင့် Wi-Fi သို့မဟုတ် wired network) လိုအပ်သည်။ Bluetooth Classic SPP thermal printer ကို Web App မှ တိုက်ရိုက်ထိန်းချုပ်နိုင်သည်ဟု မယူဆရပါ။
- Web Bluetooth သည် BLE GATT device များအတွက်သာ ဖြစ်ပြီး Bluetooth Classic SPP ကို အစားမထိုးနိုင်ပါ။ iOS Chrome/Safari မှ Website တစ်ခုက Bluetooth device ကို တိုက်ရိုက်ချိတ်ဆက်ပေးနိုင်ခြင်း မရှိပါ။

Official references:
- Chrome: https://support.google.com/chrome/answer/6362090
- Chrome Android print: https://support.google.com/chrome/answer/1069693
- MDN Web Serial: https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API
- Apple AirPrint: https://support.apple.com/en-gb/109349

## စမ်းသပ်ရန်

1. Owner နဲ့ Cashier Device တစ်ခုချင်းစီမှာ POS ကိုဖွင့်ပါ။
2. Paper Width ကို Printer ရဲ့ 58mm သို့မဟုတ် 80mm အတိုင်း ရွေးပါ။
3. `Test Print` နှိပ်ပါ။ Print Dialog မှာ paired/installed printer ပေါ်မပေါ် စစ်ပါ။
4. Test Slip ကို ထုတ်ပြီး မြန်မာစာ၊ အက္ခရာပုံစံ၊ စက္ကူဖြတ်တောက်မှု၊ အကျယ်ကို စစ်ပါ။
5. POS မှာ ပစ္စည်းတစ်ခုကို test sale လုပ်ပါ။ Checkout ပြီးနောက် Print ရွေးပါ။ နောက်တစ်ကြိမ် test sale လုပ်ပြီး No Print ရွေးကာ Total-only screen ကို စစ်ပါ။
6. Sale History မှ Voucher ပြန် Print လုပ်ကြည့်ပါ။

## မစမ်းရသေးသည့်အချက်များ

ဒီအလုပ်လုပ်နေသော environment မှာ တကယ့် printer hardware မရှိသဖြင့် Bluetooth pairing, print service, စက္ကူထုတ်မှုကို hardware ပေါ်မှာ အတည်မပြုနိုင်ပါ။ npm dependency install timeout ဖြစ်သောကြောင့် Full `npm run build` လည်း မပြီးသေးပါ။ TS/TSX syntax transpile စစ်ဆေးမှုသာ အောင်မြင်ထားသည်။

## Direct Bluetooth ကို နောက်တစ်ဆင့်လုပ်ရန် လိုအပ်သော အချက်အလက်

Bluetooth ကို App အတွင်းကနေ တိုက်ရိုက်ချိတ်ဆက်ပြီး ESC/POS data ပို့ရန် Printer ရဲ့ Brand/Model, Bluetooth type (Classic SPP သို့မဟုတ် BLE), 58mm/80mm, Android/Mac/iPhone အသုံးပြုမည့် Device တို့ သိရန်လိုသည်။ Printer မော်ဒယ်မတူလျှင် protocol/encoding ကွာနိုင်ပြီး မြန်မာစာကို raster image နဲ့ထုတ်ရမလား၊ printer code page ပံ့ပိုးသလား စမ်းသပ်ရမည်။
