# v2.9.9 စတင်အသုံးပြုရန်

1. လက်ရှိ Project ကို backup လုပ်ပါ။
2. ဒီ ZIP ကို folder အသစ်ဖြင့် ဖြည်ပါ။
3. လက်ရှိသုံးနေသော `.env` ရှိပါက လုံခြုံစွာ ပြန်ထည့်ပါ။ Firebase Config သည် `minimart-production` ကို ဆက်သုံးရမည်။
4. `npm install`
5. `npm run typecheck`
6. `npm run build`
7. Build အောင်မြင်မှသာ local/device test နှင့် deploy လုပ်ပါ။

Phone မှာ POS ကို ပြန်ဖွင့်ပြီး hard refresh လုပ်ပါ။ PWA install သုံးနေပါက app ကို ပိတ်/ပြန်ဖွင့်ပြီး updated CSS ရောက်လာကြောင်း စစ်ပါ။ Site Data, LocalStorage, IndexedDB မရှင်းပါနှင့်။
