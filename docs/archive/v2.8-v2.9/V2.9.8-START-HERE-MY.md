# Minimart v2.9.8 — စတင်အသုံးပြုရန်

1. Laptop နှင့် Phone နှစ်ခုလုံးမှ JSON Backup ထုတ်ပါ။
2. Project အသစ် Folder အဖြစ် ZIP ကို ဖြည်ပါ။ `.env` ကို အသုံးပြုထားပါက မူလ `.env` ကို လုံခြုံစွာ ပြန်ထည့်ပါ။ Firebase Config (`minimart-production`) ကို မပြောင်းပါနှင့်။
3. Terminal မှ `npm install` ပြီးနောက် `npm run typecheck` နှင့် `npm run build` အောင်မြင်ကြောင်း စစ်ပါ။
4. Firebase Console → Firestore → Rules တွင် လက်ရှိ Rules ကို Backup လုပ်ပြီး ZIP ထဲက `firestore.rules` ကို နှိုင်းယှဉ်ပေါင်းစည်းကာ Publish လုပ်ပါ။ Owner UID နှင့် Business ID ကို မပြောင်းပါနှင့်။
5. Laptop မှ Owner Login ဝင်ပြီး Cashier တစ်ယောက်က Online Sale တစ်ခု စမ်းပါ။ Cashier transaction က မိမိပိုင် `auditEvents/{saleId}__created` ကို idempotency အတွက် get လုပ်နိုင်ရမည်။ Owner → Activity Log → Cloud Sales Audit ထဲမှာ `SALE_CREATED` ပေါ်မပေါ် စစ်ပါ။
6. Owner က Cash သို့မဟုတ် မပေးချေရသေးသော Credit Sale ကို Void လုပ်ရာမှာ အကြောင်းပြချက်ထည့်ပါ။ Audit Event `SALE_VOIDED`၊ Sale Status `voided`၊ Product Stock နှင့် Stock Batch ပြန်တိုးမှုကို စစ်ပါ။
7. ထပ်မံ Void မလုပ်နိုင်ကြောင်းနှင့် Stock ထပ်မတိုးကြောင်း စမ်းပါ။
8. ပြီးမှ Phone ကို ချိတ်ပြီး Cashier Sale Sync ကို စမ်းပါ။

## သတိပြုရန်

- ဒီ Version က Cash Refund / Partial Refund မလုပ်ပါ။ Void လုပ်ခြင်းသည် Stock ပြန်ပေါင်းခြင်းဖြစ်ပြီး ငွေပြန်အမ်းခြင်းမဟုတ်ပါ။
- Cloud ထဲမရောက်သေးသော Sale ကို Void လုပ်မရပါ။
- Rules Publish မလုပ်မချင်း Cashier Sale Audit နှင့် Owner Void ကို စမ်းသပ်မထားပါနှင့်။
- Firebase Live Transaction, Hardware Print နှင့် Phone Camera စမ်းသပ်မှုများကို အသုံးပြုသူ့ Project ပေါ်မှာ အတည်ပြုရပါမည်။
