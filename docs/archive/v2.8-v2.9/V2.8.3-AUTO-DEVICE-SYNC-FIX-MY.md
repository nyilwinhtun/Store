# Minimart v2.8.3 — Auto Device Sync Fix

## ဘာကြောင့် Data မတူခဲ့သလဲ

v2.8.2 တွင် Auto Sync သည် Device တစ်ခုချင်းစီ၏ LocalStorage Sync Baseline ရှိမှသာ စတင်သည်။ Device အသစ်တွင် Baseline မရှိပါက Firebase Owner Account တူသော်လည်း Listener မချိတ်ဆက်နိုင်ပါ။

ထို့အပြင် Customer/Supplier ၏ `shared/{kind}/records/{recordId}` Firestore Rules ကို Firebase Console တွင် Publish မလုပ်ရသေးလျှင် Listener နှစ်ခုသည် `permission-denied` ဖြစ်ပြီး အခြား Branch Data Sync ကိုပါ စောင့်ခိုင်းထားသည်။

## v2.8.3 ပြင်ဆင်ချက်

1. Owner Device အသစ်သည် Login + Owner Access အတည်ပြုပြီးနောက် Cloud နှင့် Local records ကို အလိုအလျောက် Safe Merge လုပ်ကာ Baseline တည်ဆောက်သည်။
2. Cloud-only records ကို Local Store သို့ ယူသည်။ Local-only records ကို Cloud သို့ တင်သည်။
3. Record ID တူပြီး payload မတူပါက conflict ပြပြီး overwrite/delete မလုပ်ပါ။
4. Customer/Supplier rules permission-denied ဖြစ်ပါက အဲဒီနှစ်မျိုးကိုသာ ယာယီ skip လုပ်ပြီး Product, Category, Stock, Sales နှင့် Branch Data Auto Sync ကို ဆက်လုပ်သည်။ Customer/Supplier data ကို မဖျက်ဘဲ Local ထဲမှာ ထိန်းထားသည်။
5. Rules ခွင့်ပြုလာပြီး Server snapshot ရရှိသည့်အခါ shared records ကို နောက်ပိုင်း Sync ပြန်လုပ်နိုင်သည်။
6. Manual Sync လုပ်သည့်အခါလည်း Shared path permission issue ကြောင့် တခြား POS Data မပျက်စေရန် guard ထည့်ထားသည်။

## Branch အလိုက် Data ပြသပုံ

Product, Stock, Sales, Purchases, Expenses စသည်တို့သည် `branchId` အလိုက် သီးခြားဖြစ်သည်။ Device နှစ်ခုလုံးက Cloud တစ်ခုတည်းကို ချိတ်ထားသော်လည်း Active Branch မတူပါက UI မှာ ပြသမည့်စာရင်း မတူနိုင်ပါ။ Laptop နှင့် Phone ပေါ်ရှိ Branch Selector မှ Branch အမည်တူကို ရွေးပြီးမှ Product အသစ် Sync ကို စမ်းသပ်ပါ။ Branch မတူစေလိုသောအခါ သီးခြားစာရင်းပြခြင်းကို ဆက်ထိန်းထားသည်။

## စမ်းသပ်ရန်

1. ဆိုင်မှာ လက်ရှိသုံးနေသော Laptop နှင့် Phone နှစ်ခုလုံးမှ Export JSON Backup ထုတ်ပါ။
2. v2.8.3 ကို GitHub Repository သို့ Update လုပ်ပြီး GitHub Actions Build/Deploy အောင်မြင်မှုစစ်ပါ။
3. Device နှစ်ခုလုံးတွင် Owner Account တူတူဖြင့် Login ဝင်ပါ။
4. Device တစ်ခုချင်းစီ၏ Cloud Sync Status မှ `Auto Sync Active` သို့မဟုတ် ပြသသော Warning ကို စစ်ပါ။
5. Branch Selector မှ Device နှစ်ခုလုံးတွင် Branch တူအောင် ရွေးပါ။ Laptop မှ Test Product တစ်ခုထည့်ပြီး Phone တွင် ပေါ်လာသလားစစ်ပါ။ ထို့နောက် Phone မှ အခြား Test Product တစ်ခုထည့်ပြီး Laptop တွင် ပြန်ပေါ်သလားစစ်ပါ။
6. Branch မတူလျှင် အခြား Branch တစ်ခုတွင်သာ ပေါ်/မပေါ်ကို သီးခြားစစ်ပါ။
7. Customer/Supplier Sync အတွက် `FIRESTORE-SHARED-RULES-PATCH-MY.md` ကို Firebase Console Rules တွင် လက်ရှိ rules မပျက်စေဘဲ ပေါင်းစပ် Publish လုပ်ပါ။

## အကန့်အသတ်

- Auto Sync သည် Owner Account အတွက်သာ ဖြစ်သည်။ Cashier Auto Sync မပါသေးပါ။
- Product Image, Local Logo/Banner, Owner Photo, Admin PIN ကဲ့သို့ Local-only data များကို Device အလိုက်သာ ထိန်းထားသည်။
- Same-ID data conflict ဖြစ်ပါက App က မျက်စိမှိတ် အစားမထိုးပါ။ Backup ထုတ်ပြီး သီးခြားဖြေရှင်းရန် လိုသည်။
