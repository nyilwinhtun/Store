# ZYWELL ZM04 — v3.2.6 Android Integration Notes

## Confirmed from manufacturer resources

- ZYWELL publishes an Android printer SDK with sample code: https://www.zywell.cloud/fileDownload/downloadEn/SDKDownloadEn.html
- The current English ZM04 product page describes a portable label/receipt printer with USB+Bluetooth or USB+Wi-Fi variants, ESC/POS emulation, adjustable paper width up to 80 mm, and 72 mm default printing width: https://www.zywell.com/zywell-zm04-80mm-label-portable-printer
- The manufacturer's older Chinese ZM04 page lists materially different printing-width/interface details: https://www.zywell.com.cn/products-0-11-p.html

## Important variant check

Do not assume every device sold as “ZM04” has the same interface or print mechanism. Before committing to the native transport, read the model/interface label on the actual printer or its box and confirm whether it is USB+Bluetooth, USB+Wi-Fi, or another variant. Confirm that the loaded paper and print-width configuration are the intended 80 mm/72 mm combination.

## Recommended implementation

1. Download and inspect the official Android SDK archive and sample app.
2. Confirm its license/redistribution rules and supported Android API level.
3. Build a small native Android printer proof-of-concept first: discover/connect, status, test text, raster bitmap, disconnect/reconnect.
4. Validate Myanmar Unicode using raster output. Do not assume the built-in printer font supports Myanmar.
5. Wrap the proven printer operations in a Capacitor plugin interface exposed to React.
6. Keep browser `window.print()` as the desktop/web fallback.
7. Persist print status separately from sale status; retry must print the same saved voucher.

## Why the native bridge is required

The existing POS uses browser `window.print()`. A web page does not have a uniform, reliable API to access Android Bluetooth Classic or USB printer transports directly. Capacitor plugins expose Android native APIs to the web app: https://capacitorjs.com/docs/plugins

The Capacitor community Bluetooth LE plugin explicitly does not support Bluetooth Classic serial/SPP; do not select it as the printer transport until the printer's actual Bluetooth profile is confirmed: https://github.com/capacitor-community/bluetooth-le
