## F. Firestore Rules Emulator

- [ ] Owner valid priceGroup Create / Update allowed.
- [ ] Cashier priceGroup get / list / create / update denied.
- [ ] Wrong Business / wrong UID denied.
- [ ] Invalid field shape denied.
- [ ] Retail <= 0 denied.
- [ ] Wholesale < 0 denied.
- [ ] Currency other than MMK denied.
- [ ] Invalid status / version denied.
- [ ] Product mirror remains branch-scoped and existing branch rules still pass.
- [ ] Group unlink/archive payload allowed for Owner only.
- [ ] Shared Price Group နှင့် Product Mirror Sync သည် Transaction တစ်ခုတည်းဖြင့် အတူတကွ commit ဖြစ်သည်။ Bundle 400 documents ကျော်လျှင် တစ်စိတ်တစ်ပိုင်း commit မလုပ်ဘဲ fail-closed ဖြစ်သည်.
- [ ] Stock Receipt / Shipment update သည် linked Product ၏ Shared Retail / Wholesale Price ကို မပြောင်းနိုင်ပါ။
- [ ] Product link / mirror price update must match `getAfter()` Shared Group membership and prices.
- [ ] Unlink must remove that Branch from `membersByBranch` in the same transaction.
- [ ] Linked Product delete is denied unless the group membership is removed atomically.
