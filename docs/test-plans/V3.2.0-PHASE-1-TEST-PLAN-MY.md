# v3.2.0 Phase 1 — Pre-release Test Plan

## A. Owner Overview
- [ ] Active Branch ၁ ခုဖြင့် Login ဝင်လျှင် မူလ Branch Dashboard ပေါ်ရမည်။
- [ ] Active Branch ၂ ခုဖြင့် Login ဝင်လျှင် ဆိုင်အားလုံး Overview ပေါ်ရမည်။
- [ ] Archived Branch များကို Overview မှ ဖယ်ထားရမည်။
- [ ] Total Sales တွင် Active Branch များ၏ Completed Sale များသာ ပါရမည်။
- [ ] Voided Sale များကို Revenue/Profit ထဲ မတွက်ရ။
- [ ] Branch တစ်ခုချင်း Product, Low Stock, Open Shift, Pending Expense ကိန်းဂဏန်း မှန်ရမည်။
- [ ] Overview မှ Cash/KPay/Finance Balance ကို မပေါင်းပြရ။
- [ ] Recent Sales မှာ Branch Name မှန်ကန်စွာ ပြရမည်။

## B. Branch Navigation
- [ ] Header Selector မှ ဆိုင်အားလုံးကို ရွေးလျှင် Overview ဖွင့်ရမည်။
- [ ] Header Selector မှ Branch တစ်ခုကို ရွေးလျှင် PIN/Authorization အပြီး သက်ဆိုင်ရာ Dashboard သို့ ဝင်ရမည်။
- [ ] Branch Management ရှိ ဖွင့်ရန် ခလုတ်က သက်ဆိုင်ရာ Branch ကို ဖွင့်ရမည်။
- [ ] Single Branch Mode တွင် All Branch Selector မပေါ်ရ။
- [ ] Cashier တွင် All Branch Selector / Overview မပေါ်ရ။
- [ ] Cashier သည် ခွင့်ပြုထားသော Branch ပြင်ပသို့ မဝင်နိုင်ရ။

## C. Cart Protection
- [ ] Cart အလွတ်ဖြင့် Branch ပြောင်းနိုင်ရမည်။
- [ ] Cart ထဲ Product ရှိပြီး Confirm ကို Cancel လုပ်လျှင် Branch နှင့် Cart မပြောင်းရ။
- [ ] Cart ထဲ Product ရှိပြီး Confirm လုပ်လျှင်သာ Cart ရှင်းပြီး Branch ပြောင်းရမည်။
- [ ] Sale Saving / Pending Durable Persistence ဖြစ်နေချိန် Branch ပြောင်း၍ မရရ။
- [ ] Overview သို့ ဝင်ရုံဖြင့် Cart မပျောက်ရ။
- [ ] Overview ကနေ မူလ Active Branch ကို ပြန်ရွေးလျှင် Cart မပျောက်ရ။

## D. Data Isolation Regression
- [ ] Branch 1 Product ကို Branch 2 Inventory တွင် မပြရ။
- [ ] Branch 1 Sale သည် Branch 2 Dashboard Revenue ထဲ မပါရ။
- [ ] Branch 1 Expense သည် Branch 2 Pending Approval Count ထဲ မပါရ။
- [ ] Branch 1 Cash Shift သည် Branch 2 Open Shift Count ထဲ မပါရ။
- [ ] Stock Transfer Existing Workflow ကို Source/Destination မှာ စမ်းသပ်ပြီး မူလအတိုင်း မှန်ကန်ရမည်။
- [ ] Product / Sale / Branch IDs မပြောင်းလဲရ။

## E. Build / Device
- [ ] `npm run typecheck` အောင်မြင်ရမည်။
- [ ] `npm run build` အောင်မြင်ရမည်။
- [ ] Desktop layout စမ်းသပ်ရမည်။
- [ ] Android Chrome layout စမ်းသပ်ရမည်။
- [ ] PWA Update ပြီးနောက် v3.2.0 app shell အသစ်ပေါ်ရမည်။
- [ ] Dark Mode မှာ Overview Card များဖတ်ရှုလို့ရရမည်။

## Release Gate
P0 မအောင်မြင်သော Test တစ်ခုရှိလျှင် Production Deploy မလုပ်ပါနှင့်။ Firebase Live Test နှင့် multi-device sync validation သည် ဒီ source-only build စစ်ဆေးမှုတွင် မပါဝင်ပါ။
