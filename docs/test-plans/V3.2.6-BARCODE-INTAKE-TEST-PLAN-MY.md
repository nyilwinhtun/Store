# v3.2.6 Code Update 01 — Barcode Intake QA

## Product-level Barcode / SKU Scan

- [ ] Product အသစ်ကို Barcode မပါ၊ SKU ပါဖြင့် ဖန်တီးနိုင်သည်။
- [ ] Product အသစ်ကို SKU မပါ၊ Barcode ပါဖြင့် ဖန်တီးနိုင်သည်။
- [ ] Product အသစ်တွင် SKU နှင့် Barcode နှစ်မျိုးလုံး ထည့်နိုင်သည်။
- [ ] SKU သို့မဟုတ် Barcode duplicate ဖြစ်ပါက Save ပယ်ချသည်။
- [ ] Stock Receiving တွင် ရှိပြီးသား Product Barcode ကို HID Scanner ဖြင့် Scan + Enter လုပ်သောအခါ Product Name / Unit အလိုအလျောက်ဖြည့်သည်။
- [ ] Product တွင် Barcode ရှိပြီးသားဖြစ်သော်လည်း SKU ကို Scan + Enter လုပ်လျှင် မှန်ကန်သော Product ကို ရှာသည်။
- [ ] SKU Scan ဖြင့် Goods Arrival Save လုပ်ပြီးနောက် Product ၏ မူရင်း Barcode မပြောင်းလဲပါ။
- [ ] မသိသေးသော Barcode ကို Scan လုပ်ပြီး Product Name / Unit ဖြည့်ကာ Save လုပ်လျှင် Product အသစ်တွင် Barcode သိမ်းသည်။
- [ ] Stock Receiving မှာ Barcode / SKU ကို Enter နှိပ်သောအခါ form ကို မတော်တဆ Submit မဖြစ်စေပါ။
- [ ] Camera Scan နှင့် manual input များ ဆက်လက်အလုပ်လုပ်သည်။

## Stock Unit Sticker Registry (လက်ရှိအပြုအမူ စစ်ဆေးရန်)

- [ ] Product ၏ current stock တွင် Unregistered Unit ကျန်ရှိမှသာ sticker barcode မှတ်ပုံတင်နိုင်သည်။
- [ ] Sticker barcode တစ်ခုကို Registry တစ်ခုလုံးတွင် ထပ်မံမှတ်ပုံတင်၍ မရပါ။
- [ ] Sticker Registry Save လုပ်ခြင်းကြောင့် Product Stock Qty မတိုးပါ။
- [ ] လက်ရှိ Stock Qty ထက် ပိုသော Unit Sticker များကို မှတ်ပုံတင်၍ မရပါ။
