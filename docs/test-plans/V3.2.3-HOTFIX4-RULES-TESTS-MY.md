# v3.2.3 Hotfix 4 — Required Firestore Rules Tests

1. Owner can create a Cashier membership for one active Branch — **allow**.
2. Owner cannot create a Cashier membership for an archived Branch — **deny**.
3. Owner cannot create a Cashier membership for a missing Branch — **deny**.
4. Owner cannot reassign a Cashier to an archived Branch — **deny**.
5. Non-owner cannot create Cashier memberships — **deny**.
6. Cashier cannot read another Branch — **deny**.

Run from the project root:

```bash
npm run test:rules
```

Java and Firebase Emulator dependencies must be installed first.
