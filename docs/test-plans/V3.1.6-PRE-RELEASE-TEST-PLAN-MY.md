## C. Expense Approval Limit

သတ်မှတ်ရန် — Branch A = 50,000 MMK.

- [ ] 40,000 MMK Expense တင်ပြပါ။ Owner Approval မလိုသည့် အခြေအနေဖြစ်သည်။
- [ ] 50,000 MMK Expense တင်ပြပါ။ သတ်မှတ်ချက်အရ Limit မကျော်သဖြင့် Approval မလိုပါ။
- [ ] 50,001 MMK Expense တင်ပြပါ။ `pending` ဖြစ်ပြီး Owner Approval စောင့်ရသည်။
- [ ] Owner က Approve လုပ်နိုင်သည်။ Approved By / Approved At ကို သိမ်းသည်။
- [ ] Approve မလုပ်မီ Branch Cash / KPay ကို သုံးခွင့်မရှိကြောင်း UI က ပြသည်။
- [ ] Owner က Reject လုပ်ရာတွင် Reason မဖြည့်လျှင် ပယ်ချမရပါ။
- [ ] Reject လုပ်ပြီး Reason ကို Cashier ပြန်မြင်နိုင်သည်။
- [ ] Branch A Limit ကို ပြင်လျှင် Branch B Limit ကို မပြောင်းပါ။
