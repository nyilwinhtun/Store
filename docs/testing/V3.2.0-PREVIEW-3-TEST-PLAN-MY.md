# v3.2.0 Preview 3 — စမ်းသပ်ရန်အစီအစဉ်

စမ်းသပ်မှုကို Production Firebase မဟုတ်ဘဲ သီးခြား Test Project / Firestore Emulator တွင် ဦးစွာလုပ်ပါ။

## A. ပုံမှန် Auto Complete

- [ ] Owner က Branch 1 မှ Branch 2 သို့ Batch Allocation ပြည့်စုံသော Product တစ်မျိုးပို့ရန်။
- [ ] Destination Cashier သည် သတ်မှတ်ထားသော Branch တစ်ခုတည်းတွင် Login ဝင်ထားရန်။
- [ ] လက်ခံအရေအတွက်သည် ပို့အရေအတွက်နှင့် တူညီပြီး Damaged = 0 ထားရန်။
- [ ] အတည်ပြုပြီးပါက Shipment `approved`, `completionMode=auto` ဖြစ်ရန်။
- [ ] Destination Product Stock သည် ပို့လာသည့် ပမာဏအတိုင်း တစ်ကြိမ်တည်းတိုးရန်။
- [ ] Destination Stock Batch များကို မူလ Batch Allocation / Expiry / Cost အတိုင်း ဖန်တီးရန်။
- [ ] Shipment, Product, Batch သုံးမျိုးလုံး Cloud မှာ အတူတကွ Commit ဖြစ်ရန်။

## B. Destination Product အသစ်ဖန်တီးခြင်း

- [ ] Destination မှာ Product မရှိသေးသည့်အခြေအနေ၊ Active Category ရှိကြောင်း စစ်ရန်။
- [ ] ပုံမှန်လက်ခံမှု Auto Complete လုပ်ရန်။
- [ ] Product အသစ်၊ Stock Batch များနှင့် Shipment Auto Status ကို Cloud တွင် မှန်ကန်စွာ ဖန်တီးရန်။
- [ ] Product ID တူညီသည့် Cloud Record ရှိနေပါက Duplicate မဖြစ်ဘဲ ရပ်တန့်ရန်။

## C. Exception / Owner Review

- [ ] ပို့ထားသည့်အရေအတွက်ထက် နည်း၍ လက်ခံရန်။
- [ ] ပျက်စီးအရေအတွက် တစ်ခုထက်ပို ထည့်ရန်။
- [ ] လက်ခံအရေအတွက် သုညဖြစ်ရန်။
- [ ] Shipment ကို `received` အဖြစ်သာ မှတ်တမ်းတင်ရန်။
- [ ] Owner Approval မလုပ်မချင်း Destination Product/Batch Stock မတိုးရန်။
- [ ] Owner က လက်ခံရရှိသည့် အရေအတွက်ကို စစ်ဆေးအတည်ပြုပြီးမှ Stock တိုးရန်။

## D. Guard / Duplicate / Conflict

- [ ] Destination Product Duplicate နှစ်ခုရှိလျှင် Auto Complete မလုပ်ရန်။
- [ ] Source Batch Allocation စုစုပေါင်းသည် Shipment Quantity နှင့် မကိုက်ပါက Auto Complete မလုပ်ရန်။
- [ ] Destination Product Stock နှင့် Batch Stock မကိုက်ညီလျှင် Auto Complete မလုပ်ရန် (သတ်မှတ်ထားသော Opening Batch Review Route ကို သုံးရန်)။
- [ ] Destination Product တွင် Unit Barcode Registry ရှိလျှင် Quantity-only Transfer ကို Block လုပ်ရန်။
- [ ] Destination Quantity Mode မတူလျှင် Auto Complete မလုပ်ရန်။
- [ ] တူညီသော Shipment ကို Cashier နှစ်ဦးက တစ်ချိန်တည်းလက်ခံရန် ကြိုးစားလျှင် Stock တစ်ကြိမ်သာတိုးရန်။
- [ ] Commit Response မသေချာသော Network Error တွင် ထပ်မံ Submit မလုပ်ရန်၊ History Refresh ဖြင့် အတည်ပြုရန်။
- [ ] Auto Complete ပြီးသား Shipment ကို ထပ်မံ Submit လုပ်၍ Stock ထပ်မတိုးနိုင်ရန်။

## E. Security Rules Emulator

- [ ] သက်ဆိုင်ရာ Branch ရဲ့ Stock Receiver သည် သတ်မှတ်ထားသော Shipment ကိုသာ Auto Complete လုပ်နိုင်ရန်။
- [ ] Receiver သည် မိမိ Branch မဟုတ်သည့် Branch ကို Write မလုပ်နိုင်ရန်။
- [ ] Receiver သည် Shipment မချိတ်ထားသော Product Create/Update မလုပ်နိုင်ရန်။
- [ ] Receiver သည် Shipment မချိတ်ထားသော Stock Batch Create မလုပ်နိုင်ရန်။
- [ ] Receiver သည် Product Price, Quantity, Category ကို အထွေထွေပြောင်းလဲခြင်း မလုပ်နိုင်ရန်။
- [ ] ပို့ထားသည့် Item / Batch Allocation မပြောင်းဘဲသာ Auto Complete လုပ်နိုင်ရန်။
- [ ] Owner ရဲ့ လက်ရှိလုပ်ပိုင်ခွင့်များ မပျက်စေရန်။
