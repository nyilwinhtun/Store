# v3.2.0 — Standalone Login Regression Test Plan

## Login Entry

- [ ] Incognito/Logged-out browser ဖြင့် Website Root ကို ဖွင့်ပါ။ Login Page သာ ပေါ်ရမည်။
- [ ] Sidebar, POS, Dashboard ကို မပြရ။
- [ ] Login Form သည် Profile Menu ထဲတွင် မရှိရ။
- [ ] Login Screen တွင် Owner Sign Up / Account Creation Button, Link သို့မဟုတ် Form မရှိရ။
- [ ] Login Screen မှာ ရှိပြီးသား Owner/Cashier Account ဖြင့်သာ Sign In လုပ်နိုင်ရ။
- [ ] Wrong Email/Password ဖြင့် Login မဝင်နိုင်ရ။ Error ကို သင့်တော်စွာ ပြရ။
- [ ] မှန်ကန်သော Owner Account ဖြင့် Login ဝင်လျှင် Access စစ်ဆေးပြီး Owner Workspace ပေါ်ရ။
- [ ] မှန်ကန်သော Cashier Account ဖြင့် Login ဝင်လျှင် သတ်မှတ် Branch POS သို့ ဝင်ရ။
- [ ] UID/Member/Branch Permission မရှိသော Account ကို App ထဲ မဝင်ခွင့်ပြုရ။
- [ ] Password Reset Email ပို့နိုင်ရ။
- [ ] Login Page တွင် Owner Account အသစ်ဖန်တီးရန် Button / Link / Form မရှိရ။
- [ ] LoginPage source တွင် `createUserWithEmailAndPassword` သို့မဟုတ် `updateProfile` ကို မခေါ်ရ။
- [ ] မရှိသေးသော Email/Password ဖြင့် Login လုပ်လျှင် Account အသစ်မဖန်တီးဘဲ Login ပယ်ချရ။
- [ ] ရှိပြီးသား Owner Account ဖြင့် Login ဝင်နိုင်ပြီး Owner Access ဆက်လက်ရရှိရ။
- [ ] Owner က Team Access ထဲမှ Cashier Account ဖန်တီးနိုင်မှုကို သီးခြား Regression Test လုပ်ရ။
- [ ] Production Owner UID / Authentication User ကို မဖျက်၊ မပြောင်းရ။

## Session & Logout

- [ ] Authenticated session ဖြင့် Refresh လုပ်လျှင် Access အတည်ပြုပြီးမှ Workspace ပေါ်ရ။
- [ ] Sign Out ခလုတ်ကို Owner နှင့် Cashier နှစ်မျိုးလုံးတွင် မြင်ရ။
- [ ] Sign Out ပြီး Root Login Page သို့ ပြန်ရောက်ရ။
- [ ] Browser Back ဖြင့် protected workspace ကို ပြန်ဖွင့်မရ။
- [ ] အခြား Account ဖြင့် Login ဝင်ရာတွင် ယခင် Account ၏ Role/Branch Access ကို မသုံးရ။

## Regression Protection

- [ ] Firebase API Key, Project ID, Business ID, Auth Config မပြောင်းထားကြောင်း Diff စစ်ပါ။
- [ ] Existing Login Validation API ကို ဆက်သုံးထားကြောင်း စစ်ပါ။
- [ ] Owner/Cashier AccessBootstrap နှင့် Firestore Rules ကို Emulator/approved test project မှာ စမ်းပါ။
- [ ] POS, Sales, Barcode, Cash/KPay, Expense, Branch Transfer, Offline Queue ကို ပြန်စမ်းပါ။
- [ ] PWA Install နှင့် GitHub Pages Root URL ကို စမ်းပါ။

## Expected Behavior

Firebase Auth Session မရှိသည့်အခါ Root တွင် Login Page ပြမည်။ Session ရှိပြီးသားဆို Access အတည်ပြုပြီးမှ Workspace ဖွင့်မည်။ Sign Out ပြီးပါက Login Page သို့ ပြန်ရောက်မည်။
