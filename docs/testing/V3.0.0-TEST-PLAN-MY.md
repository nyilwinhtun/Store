# v3.0.0 စမ်းသပ်ရန် Checklist

## Build / Access
- [ ] `npm run typecheck` အောင်မြင်
- [ ] `npm run build` အောင်မြင်
- [ ] Owner Login အောင်မြင်
- [ ] Cashier Login အောင်မြင်
- [ ] Owner UID / Business ID မှန်
- [ ] Receiver Permission ပိတ်ထားသည့် Cashier သည် Receiving Page မမြင်ရ
- [ ] Receiver Permission ဖွင့်ထားသည့် Cashier သည် Assigned Branch တစ်ခုတည်းကိုသာ ဝင်နိုင်

## Dispatch
- [ ] Branch ၂ ခု Active ဖြစ်
- [ ] Owner က Source/Destination Branch မတူအောင် ရွေးနိုင်
- [ ] Shipment တစ်ခုတွင် Product အများအပြား ထည့်နိုင်
- [ ] Product ၅၀ ထက်မကျော်စေ
- [ ] Duplicate Product တစ်မျိုး ထပ်ထည့်ခြင်းကို တားနိုင်
- [ ] Stock ထက်ပိုသော Qty ကို တားနိုင်
- [ ] Dispatch လုပ်ပြီး Source Product Stock လျှော့
- [ ] Source Stock Batch လျှော့ပြီး Batch စုစုပေါင်းနှင့် Product Stock ကိုက်ညီ
- [ ] Request ကို ထပ်နှိပ်/Retry လုပ်လျှင် Shipment ထပ်မဖန်တီး
- [ ] Shipment Cloud သို့ Sync အောင်မြင်

## Receiving
- [ ] Assigned Receiver ကသာ Shipment ကို မြင်ရ
- [ ] အခြား Branch Cashier က Shipment ကို မမြင်ရ
- [ ] Received Qty ကို Shipped Qty ထက် မပိုစေ
- [ ] Damaged Qty ကို Received Qty ထက် မပိုစေ
- [ ] Zero received / all damaged အခြေအနေကို လက်ခံနိုင်
- [ ] Receiver Confirm ပြီးချိန် Destination Stock မတိုးသေး
- [ ] Receipt transaction တစ်ကြိမ်ထက်ပို submit မဖြစ်
- [ ] Receiver က Product/Stock ကို တိုက်ရိုက် update မလုပ်နိုင်

## Owner Approval / Cancel
- [ ] Owner သာ Approve လုပ်နိုင်
- [ ] Invalid/Out-of-range received quantity ကို Owner Approval တားနိုင်
- [ ] Approve ပြီး Destination Product ရှိလျှင် Stock တိုး
- [ ] Destination Product မရှိလျှင် Product/Category ဖန်တီး
- [ ] SKU/Barcode/Unit/Cost/Retail/Wholesale Price Snapshot မှန်
- [ ] Accepted Qty = Received Qty - Damaged Qty
- [ ] Destination Stock Batch ပမာဏနှင့် Product Stock ကိုက်ညီ
- [ ] Approve ဒုတိယအကြိမ် မလုပ်နိုင်
- [ ] Receiver မလက်ခံမီ Owner Cancel လုပ်လျှင် Source Stock/Batch ပြန်တိုး
- [ ] Received ဖြစ်ပြီးနောက် Cancel မလုပ်နိုင်
