# v3.1.0 Phase 1 — Safety & Compatibility Test Plan

ဒီ Phase သည် schema foundation သာဖြစ်ပြီး လက်ရှိ App behavior မပြောင်းသင့်ပါ။

## Source Compatibility

- [ ] Existing Expense JSON (id/title/category/amount/date/note/branchId သာပါသော) ကို load လုပ်နိုင်ရန်။
- [ ] Existing LocalStorage data ကို မဖျက်ဘဲ app က ဆက်ဖတ်နိုင်ရန်။
- [ ] Backup Export / Import တွင် Expense fields အဟောင်းများ မပျောက်ရန်။
- [ ] New optional Expense fields မရှိသေးသည့် record များကြောင့် error မဖြစ်ရန်။
- [ ] `src/types/finance.ts` type contracts သာဖြစ်ပြီး runtime Firestore read/write မလုပ်ကြောင်း စစ်ရန်။

## Preserve Existing Features

- [ ] Firebase Auth / Owner Login / Cashier Login တူညီစွာ အလုပ်လုပ်ရန်။
- [ ] POS checkout, Cash underpayment protection, Credit sale မပျက်ရန်။
- [ ] Barcode scan / Retail / Wholesale price မပျက်ရန်။
- [ ] Stock transfer / Shipment / Receiving / Owner Approval မပျက်ရန်။
- [ ] Offline POS / queue / Cloud Sync မပျက်ရန်။
- [ ] Firestore Rules မပြောင်းထားကြောင်း စစ်ရန်။

## Build Verification

Run on the developer Mac after installing dependencies:

```bash
npm install
npm run typecheck
npm run build
```

## Phase 1 Release Gate

Phase 1 ကို source-preparation package အဖြစ်သာ သတ်မှတ်ရန်။ `npm run typecheck`, `npm run build`, local app test မအောင်မြင်သေးလျှင် production deploy မလုပ်ရ။ Cashier finance runtime feature, FCM push, Firestore Rules update တို့ကို ဒီ Phase 1 package မှာ မပါဝင်စေရ။
