# v3.2.0 Preview 3 — Release Gate / မဖြစ်မနေသိရန်

## လက်ရှိစစ်ဆေးပြီးသည့်အရာ

- TypeScript / TSX ၄၁ ဖိုင်ကို Global TypeScript Parser ဖြင့် parse လုပ်ရာ Syntax Parser Error မရှိခဲ့ပါ။
- Firestore Rules ဖိုင်အတွက် bracket/parenthesis balance စစ်ရာ မှားယွင်းမှု မတွေ့ပါ။
- Custom Rules Function တစ်ခုချင်းစီ၏ `let` binding အရေအတွက်ကို စစ်ရာ Function တစ်ခုလျှင် ၁၀ ထက်မပိုပါ။
- Preview 2 နှင့် နှိုင်းယှဉ်ရာ `src/lib/firebase.ts`, `src/lib/businessAccess.ts`, `src/lib/branchShipmentCloudCommit.ts`, `src/lib/branchShipmentSync.ts`, `src/components/CashierAutoSync.tsx`, `src/components/OwnerAutoSync.tsx` မပြောင်းထားပါ။

## မပြီးသေးသော Release Gate

- [ ] `npm install` အောင်မြင်ရန်။ ဒီ Preview ပြုလုပ်စဉ် Dependency Install သည် Timeout ဖြစ်ခဲ့သည်။
- [ ] `npm run build` အောင်မြင်ရန်။ လက်ရှိ Vite Full Build ကို မစမ်းသပ်နိုင်သေးပါ။
- [ ] Firebase CLI / Firestore Emulator ဖြင့် `firestore.rules` Compile နှင့် Unit Test လုပ်ရန်။ Emulator ကို ဒီ Environment တွင် မရရှိသဖြင့် Rules ကို Compile/Test မလုပ်နိုင်သေးပါ။
- [ ] Auto Complete positive/negative tests အားလုံး အောင်မြင်ရန်။
- [ ] Branch 1 / Branch 2 Device နှစ်လုံးဖြင့် Multi-device test လုပ်ရန်။
- [ ] Production Data Backup နှင့် Rollback Plan ပြုလုပ်ရန်။
- [ ] Production Rules Publish မလုပ်ခင် Owner က အတည်ပြုရန်။

## အရေးကြီးတဲ့ Safety Limit

ဒီ Preview ရဲ့ Auto Complete သည် Cashier Web Client မှ Firestore Transaction တစ်ခုတည်းဖြင့် Destination Product, Batch နှင့် Shipment ကို သိမ်းသည်။ Rules များက Receiver ကို သတ်မှတ်ထားသော Shipment နှင့် ချိတ်ဆက်ထားသည့် Write များသာ ခွင့်ပြုရန် ရည်ရွယ်ထားသည်။ သို့သော် Rules Emulator Test မအောင်မြင်မချင်း Production Security အဖြစ် မယူဆရပါ။ Client-side atomic transaction ဖြစ်သောကြောင့် production hardening အတွက် Emulator tests နှင့် လိုအပ်ပါက trusted backend/Cloud Function ဖြင့် finalization စဉ်းစားရမည်။

## Unit Barcode Transfer

Barcode တစ်ခုချင်းစီကို Branch 1 မှ Branch 2 သို့ လွှဲပြောင်းသည့် Unit-level Transfer မပါသေးပါ။ Unit Barcode Registry ရှိပြီးသား Product ကို Quantity-only Shipment ဖြင့် လက်ခံခြင်းကို ကာကွယ်ထားသည်။ Barcode Unit Transfer မရမချင်း ထို Product များကို ဒီ Shipment Workflow မှ မပို့ပါနှင့်။

## Online Requirement

Auto Complete သည် Online လိုအပ်သည်။ Offline ဖြစ်ပါက Destination Stock ကို Local မှာ အပြီးသတ်မတိုးပါ။ Shipment History နှင့် Cloud State ကို စစ်ဆေးပြီးမှ ပြန်ကြိုးစားပါ။

**အဆုံးသတ်:** ဒီဖိုင်သည် Developer Preview ဖြစ်ပြီး Production Release Candidate မဟုတ်သေးပါ။
