# v3.2.0 Preview 2 — စမ်းသပ်ရန်အစီအစဉ်

## A. Owner Dashboard

1. Owner Account ဖြင့် Login ဝင်ပါ။
2. Dashboard ကိုဖွင့်ပြီး `ဆိုင်အားလုံး` ကိုရွေးပါ။ ဆိုင်ခွဲအားလုံး၏ ယနေ့အရောင်းနှင့် Branch Cards ပေါ်ရမည်။
3. Branch 1 ကိုရွေးပါ။ Metric, Trend, Low Stock, Recent Transactions သည် Branch 1 သာဖြစ်ရမည်။
4. Branch 2 ကိုရွေးပြီး ထပ်စစ်ပါ။ Branch 2 အချက်အလက်သာ ဖြစ်ရမည်။
5. Dashboard filter ဖြင့် Branch ပြောင်းသော်လည်း Topbar Active Branch မပြောင်းရ။ POS / Inventory ကိုဖွင့်လျှင် မူလ Active Branch context အတိုင်း ဖြစ်ရမည်။
6. Owner All Branches view တွင် Recent Transactions ဇယား၌ Branch Name မှန်ရမည်။
7. Branch တစ်ခု၏ Product ID နှင့် အခြား Branch Product ID ထပ်နေသည့် data စမ်းသပ်နိုင်ပါက Product row / Low Stock row များ ရောမသွားရ။

## B. Cashier Scope

1. Branch 1 Cashier Login ဝင်ပါ။ Dashboard မှာ All Branches selector မပေါ်ရ။
2. Branch 1 Data သာ ပြရမည်။ URL/Local State ဖြင့် Branch 2 data မဖွင့်နိုင်ရ။
3. Branch 2 Cashier အတွက်လည်း ထပ်စစ်ပါ။

## C. Shipment Exception Classification

1. ပို့ထားသော 10၊ လက်ခံ 10၊ ပျက်စီး 0 => `အရေအတွက်ကိုက်ညီ · Stock Commit စောင့်နေ` ဖြစ်ရမည်။
2. ပို့ထားသော 10၊ လက်ခံ 9၊ ပျက်စီး 0 => `ကွာခြားချက်ရှိ · Owner Review` ဖြစ်ရမည်။
3. ပို့ထားသော 10၊ လက်ခံ 10၊ ပျက်စီး 1 => `ကွာခြားချက်ရှိ · Owner Review` ဖြစ်ရမည်။
4. Shipment Summary ရှိ လက်ခံရန်ကျန်၊ ကိုက်ညီ၊ Exception အရေအတွက်ကို History နဲ့ တိုက်စစ်ပါ။
5. Owner approval ပြီးနောက် Stock, Batch, History မှတ်တမ်းတွေကို ယခင်အတိုင်း စစ်ပါ။
