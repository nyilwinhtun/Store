# Minimart POS v3.1.0 — Phase 1 စတင်အသုံးပြုနည်း

ဒီ ZIP သည် v3.0.2 ကို အခြေခံထားသော **Phase 1 Architecture Foundation Preview** ဖြစ်သည်။ Cashier Expense UI, KPay Settlement UI, FCM Notification နှင့် Firestore Rules အသစ်များကို မဖွင့်ရသေးပါ။

## အရေးကြီး

1. မူလ v3.0.2 project folder ကို မဖျက်ပါနှင့်။ Backup ZIP ကို သီးခြားထားပါ။
2. ဒီ package ကို folder အသစ်တစ်ခုထဲ ဖြည်ပါ။
3. မိမိအသုံးပြုနေသော `.env` ကို လိုအပ်သလို ပြန်ထည့်ပါ။ `.env.example` ကိုကြည့်ပြီး Firebase config ကို မိမိ project နဲ့ တိုက်စစ်ပါ။
4. Firebase Console ထဲက Firestore Rules ကို ဒီ Phase 1 အတွက် မပြောင်းပါနှင့်။ ဒီ ZIP ၏ `firestore.rules` သည် v3.0.2 baseline အတိုင်းဖြစ်သည်။
5. Terminal မှာ `npm install`, `npm run typecheck`, `npm run build` ကို run ပါ။
6. Local app ဖွင့်ပြီး Owner Login, Cashier Login, POS, Stock, Shipment/Receiving ကို ပြန်စမ်းပါ။

## ပြောင်းထားသောအရာ

- `src/types/finance.ts` — v3.1.0 အတွက် Finance / Cashier Settlement / Branch KPay / Shipment Push compile-time contracts အသစ်။
- `src/store/usePosStore.ts` — ရှိပြီးသား `Expense` အတွက် optional metadata fields ကို type-level တွင်သာ ချိတ်ဆက်ထားသည်။ Existing data များကို migrate မလုပ်ပါ။
- `V3.1.0-PHASE-1-ARCHITECTURE-MY.md` — လက်ရှိ Source audit, proposed data shape, permission matrix, Firebase optimization design။
- `V3.1.0-PHASE-1-TEST-PLAN-MY.md` — compatibility နှင့် regression test checklist။

## Version အကြောင်း

`package.json` runtime version ကို `3.0.2` အတိုင်း ထားထားသည်။ ဒီ package သည် Phase 1 preparation ဖြစ်ပြီး full v3.1.0 application release မဟုတ်သေးပါ။ Runtime feature နှင့် Firestore Rules test ပြီးမှ app version ကို 3.1.0 သို့ ပြောင်းမည်။
