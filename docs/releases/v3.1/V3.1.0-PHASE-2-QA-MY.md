# Minimart POS v3.1.0 Preview.2 — Phase 2 QA မှတ်တမ်း

## ဒီ Phase မှာ ထည့်ထားသောအရာ

- Owner-only `တစ်ဘူးချင်း Barcode` Registration Page
- ရှိပြီးသား Unique Manufacturer Serial ကို Bluetooth Scanner / Camera / Paste ဖြင့် မှတ်ပုံတင်ခြင်း
- မရှိသေးသော Unit များအတွက် Secure Random 64-bit ID + Code 128 Label Generate / Print / Reprint
- Product + Branch + Chunk Registry; Registry တစ်ခုလျှင် Unit ၂၅၀ အထိ
- LocalStorage migration, JSON Backup / Restore နှင့် Owner Cloud Sync ချိတ်ဆက်မှု
- Product Barcode / EAN (ဘူးတိုင်းတူညီသော code) ကို Unit Barcode အဖြစ် အသုံးပြုခြင်းကို တားမြစ်ခြင်း

## လုပ်ဆောင်ပြီးသော စမ်းသပ်မှု

- TypeScript / TSX ဖိုင် ၃၃ ခုကို TypeScript transpile parser ဖြင့် စစ်ဆေးရာ Syntax Diagnostic ၀ ခု။
- Code 128 Pattern Table ၁၀၇ ခုကို သီးခြား Reference Table နှင့် နှိုင်းယှဉ်ရာ အားလုံးကိုက်ညီသည်။
- Store Action Test: Stock ၅၀၀ ရှိသော Product အတွက် Unit ၃၀၀ မှတ်ပုံတင်ရာ ၂၅၀ + ၅၀ အဖြစ် Registry ခွဲသိမ်းနိုင်သည်။
- Unit မှတ်ပုံတင်သော်လည်း Product Stock ၅၀၀ မပြောင်းကြောင်း စစ်ဆေးပြီးဖြစ်သည်။
- Duplicate Unit Barcode, Product EAN, Stock ထက်ကျော်သော Registration တို့ကို Reject လုပ်ကြောင်း စစ်ဆေးပြီးဖြစ်သည်။
- မူလ `firestore.rules`, Firebase Config, Business Access, Branch Shipment Management နှင့် Branch Receiving files တို့ v3.0.2 မူရင်းနှင့် မပြောင်းလဲကြောင်း နှိုင်းယှဉ်စစ်ဆေးပြီးဖြစ်သည်။

## မစမ်းသပ်ရသေးသောအရာ / Release Gate

- ဒီပတ်ဝန်းကျင်တွင် `node_modules` မရှိပါ။ `npm ci` အတွက် `package-lock.json` မူရင်း Project ထဲတွင် မရှိသဖြင့် မလုပ်နိုင်ခဲ့ပါ။ `npm install` ကို ကြိုးစားရာ installation timeout ဖြစ်ခဲ့သည်။ ထို့ကြောင့် Full `npm run typecheck` နှင့် `npm run build` ကို အောင်မြင်သည်ဟု မဆိုနိုင်ပါ။
- Physical Barcode Scanner ဖြင့် Print Label အတိအကျ Scan စမ်းသပ်ခြင်း မပြီးသေးပါ။
- Owner Device နှစ်လုံးအကြား Live Firebase Cloud Sync / Duplicate conflict စမ်းသပ်မှု မပြီးသေးပါ။
- Shipment Unit Manifest, Cashier Receiving Scan/Quantity, Owner Approval မှ Unit Status ပြောင်းခြင်းနှင့် POS Unit-level Sale ကို ဒီ Phase မှာ မချိတ်ဆက်သေးပါ။

## Production အသုံးပြုမှုမတိုင်မီ

1. Project ကို သီးခြား Test Folder ထဲ Extract လုပ်ပါ။ လက်ရှိ Production Project ကို Overwrite မလုပ်ပါနှင့်။
2. Mac Terminal မှ Project Folder ထဲဝင်၍ `npm install` လုပ်ပါ။
3. `npm run typecheck` နှင့် `npm run build` အောင်မြင်ကြောင်း စစ်ပါ။
4. Test Branch / Test Product တစ်ခုဖြင့် 10 Unit Register၊ Label Print၊ Scanner Test၊ Refresh၊ Backup/Restore နှင့် Cloud Sync ကို စမ်းပါ။
5. စမ်းသပ်မှုအားလုံးပြီးမှ နောက် Phase တွင် Shipment / Receiving / POS integration ကို ဆက်တည်ဆောက်ပါ။

**အရေးကြီး:** ဒီ Preview က Unit Barcode Registration အဆင့်သာဖြစ်သည်။ Unit Barcode ကို POS sale အတွက် အသက်ဝင်စေခြင်း မလုပ်သေးသောကြောင့် Production Sales အတွက် တစ်ဘူးချင်း Barcode ဖြင့် ရောင်းရန် မသုံးသေးပါနှင့်။
