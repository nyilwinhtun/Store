# v3.2.5 Hotfix 1 — Cashier Sale Legacy Item Type Fix

## ပြင်ဆင်ချက်

`src/lib/cashierSalesSync.ts` ရှိ `legacySaleMatches()` မှာ Firestore မှဖတ်လာတဲ့ `existing.items` ကို callback အတွင်း တိုက်ရိုက် index လုပ်ရာ TypeScript က array narrowing ကို closure အတွင်း မထိန်းနိုင်လို့ TS7053 ဖြစ်ခဲ့ပါတယ်။

ယခု ပြင်ဆင်မှုမှာ:

- `Array.isArray(existing.items)` နဲ့ array ဖြစ်ကြောင်း အရင်စစ်ဆေးထားသည်။
- စစ်ဆေးပြီးသော items ကို `unknown[]` local constant болгон хадгална.
- Item တစ်ခုချင်းစီကို `unknown` အဖြစ်ဖတ်ပြီး object ဖြစ်ကြောင်း၊ array မဟုတ်ကြောင်း စစ်ဆေးပြီးမှ `Record<string, unknown>` အဖြစ် အသုံးပြုသည်။
- `any` မသုံးထားပါ။ Sale ID, Voucher, Product, Quantity, Price, Price Group, Version နဲ့ Batch Allocation နှိုင်းယှဉ်မှု logic မပြောင်းထားပါ။
