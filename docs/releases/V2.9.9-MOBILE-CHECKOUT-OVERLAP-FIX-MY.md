# Minimart v2.9.9 — Mobile Checkout Overlap Fix

## ပြင်ဆင်ချက်
- Phone POS မှာ Checkout & Save Sale ခလုတ်ကို `position: sticky` မသုံးတော့ဘဲ normal flow ထဲထားသည်။
- Mobile POS မှာ Receipt paper width / Test Print controls ကို Checkout အောက်မှာ မပြစေတော့ပါ။ Printer setting ကို Settings ထဲမှ ဆက်လက်အသုံးပြုနိုင်သည်။
- Checkout ခလုတ်အတွက် `text-shadow` နှင့် `box-shadow` ကို ဖယ်ထားပြီး label ကို တစ်ထပ်တည်းပေါ်စေသည်။
- Cart summary ရဲ့ safe-area padding နဲ့ note spacing ကို ပြန်ညှိထားသည်။

## မပြောင်းထားသောအရာများ
- Firebase Project Config (`minimart-production`)၊ Business ID၊ Owner/Cashier Authentication
- Cashier Cloud Sales၊ Stock Transaction၊ Sales Audit၊ Void logic
- Barcode Scan၊ Receipt modal၊ Desktop/Laptop POS layout
- Product/Sales data schema
