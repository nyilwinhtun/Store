# Minimart POS v3.2.4 — Performance & Production Readiness

## ရည်ရွယ်ချက်

v3.2.3 Hotfix 5 ၏ Security, Login, Shared Pricing, Branch နှင့် POS လုပ်ဆောင်ချက်များကို ထိန်းသိမ်းပြီး ပထမဆုံးဖွင့်ချိန် JavaScript ပမာဏ လျှော့ချရန်၊ Developer QA ကို command တစ်ခုတည်းဖြင့် စစ်နိုင်ရန် ဖြစ်သည်။

## ပြင်ဆင်ချက်များ

- Owner/Cashier စာမျက်နှာများကို React `lazy()` ဖြင့် လိုအပ်ချိန်မှသာ load လုပ်သည်။
- Barcode Camera Scanner (`@zxing`) ကို Scanner ဖွင့်သည့်အချိန်မှသာ load လုပ်သည်။
- Login နှင့် Workspace Page များအတွက် Suspense fallback ထည့်ထားသည်။
- PWA precache manifest တွင် initial entry JavaScript နှင့် shared CSS/font များသာ ထည့်သည်။ Lazy route chunks များကို ပထမဆုံးအသုံးပြုချိန်တွင် Service Worker က runtime cache လုပ်သည်။
- Service Worker cache version ကို v3.2.4 သို့ မြှင့်ထားသည်။ LocalStorage နှင့် IndexedDB business data ကို မဖျက်ပါ။
- `npm run qa` ဖြင့် Security Preflight, TypeScript, Functions Build, Firestore Rules Emulator Test, Website Build နှင့် Bundle Report ကို အစဉ်လိုက်စစ်နိုင်သည်။
- `npm run qa:quick` သည် Java/Emulator မပါဘဲ အခြား QA အပိုင်းများကို စစ်သည်။
- `npm run report:bundle` ဖြင့် Entry/Lazy JavaScript file size၊ gzip နှင့် Brotli size များကို ကြည့်နိုင်သည်။

## မပြောင်းထားသော အရေးကြီးအပိုင်းများ

- Firebase Authentication နှင့် Firebase Project Configuration
- Firestore Rules များ
- Owner/Cashier Business Access Logic
- Product ID, Branch ID နှင့် Shared Price Group Data Model
- Sale, Stock, Cash, KPay နှင့် Stock Transfer transaction logic

## QA မှတ်ချက်

ဒီ Source Package ကို ထုတ်သည့်အချိန်တွင် Dependency install နှင့် Full Build ကို ဒီ build environment မှ အတည်မပြုနိုင်ခဲ့ပါက Release Candidate အဖြစ်သာ သတ်မှတ်ရမည်။ အသုံးပြုမည့် Mac တွင် `npm install` ပြီးနောက် `npm run qa` ကို အောင်မြင်စွာ run လုပ်ပြီးမှ Production deploy လုပ်ပါ။

## PWA Offline အပြုအမူ

Lazy-loaded စာမျက်နှာတစ်ခုကို Device ပေါ်တွင် ပထမဆုံးဖွင့်သည့်အခါ Internet လိုအပ်နိုင်သည်။ အဲဒီ chunk ကို ပထမဆုံး fetch လုပ်ပြီးနောက် Service Worker က cache လုပ်ထားမည်။ Release အသစ်သို့ ပြောင်းချိန်တွင် အဟောင်းနှင့် အသစ် assets များကို စနစ်တကျ cache ပြောင်းလဲမည်။
