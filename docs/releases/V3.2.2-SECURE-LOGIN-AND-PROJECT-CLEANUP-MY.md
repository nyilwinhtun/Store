# Minimart POS v3.2.2 — Secure Login & Project Cleanup

## အဓိကပြင်ဆင်ချက်များ

- Website ပထမစာမျက်နှာသို့ Login Page ပြောင်းထားသည်။
- Public Sign Up / Owner Account Create UI ကို ဖယ်ရှားထားသည်။
- Guest / Local unauthenticated workspace fallback ကို ပိတ်ထားသည်။
- Only Owner UID သို့မဟုတ် Active Cashier Member သာ App Workspace ဝင်နိုင်သည်။
- Cashier Account ကို App ထဲမှ Auth Account အသစ်ဖန်တီးခြင်း မလုပ်နိုင်တော့ပါ။ ရှိပြီးသား Firebase Auth User ကို Owner က UID ဖြင့် Member ချိတ်ဆက်နိုင်သည်။
- Firebase Identity Platform Blocking Function Source ထည့်ထားသည်: public account creation block နှင့် Owner/Cashier/Active Branch sign-in authorization (7-second blocking timeout).
- Cashier ဝင်ခွင့်စစ်ရာတွင် `members/{uid}` email/UID/role/status/Branch နှင့် Branch `payload.status == active` ကို Server မှ စစ်သည်.
- Login တွင် Identity Platform Blocking Function မှ ပယ်ချမှုအတွက် `auth/internal-error` အကြောင်းကြားချက် ထည့်ထားသည်.
- Functions runtime ကို Node.js 22 သို့ မြှင့်ထားသည်; Firestore Rules ဖိုင်ကို Firebase CLI config တွင် ထင်ရှားစွာ သတ်မှတ်ထားသည်.
- Firestore Rules ၏ `isActiveMember()` ကို Active Cashier အဖြစ် ပိုမိုတင်းကျပ်ထားသည်။ Business Root Document ကို configured Owner သာ initialize လုပ်နိုင်သည်။
- Root Folder မှ Markdown Documentation အများစုကို `docs/` အုပ်စုခွဲထားသည်။ Source နှင့် build configuration ဖိုင်များကို Root တွင် ထားသည်။
- PWA cache namespace နှင့် Version `3.2.2` သို့ မြှင့်ထားသည်။

## မပြောင်းထားသောအပိုင်းများ

- Firebase Web Config / Project ID / Business ID
- Firebase Authentication Sign-In
- Business Owner UID နှင့် Cashier Member Mapping Data
- Multi-Branch Foundation၊ Shared Price Group၊ Product ID၊ Sale History၊ Stock Transfer Logic
- လက်ရှိ Firestore Collections / Local Store Schema

## လိုအပ်သော Firebase Console အဆင့်

Server-side Auth Blocking Function အပြည့်အဝ အသက်ဝင်ရန် Firebase Authentication ကို Identity Platform သို့ Upgrade လုပ်ပြီး Functions Deploy လုပ်ရန် လိုအပ်သည်။ အသေးစိတ်ကို `docs/firebase/ACCOUNT-ACCESS-SECURITY-MY.md` တွင်ကြည့်ပါ။

## QA အခြေအနေ

Source ပြင်ဆင်မှုသာ ပြီးစီးထားသည်။ Dependency များကို Install လုပ်၍ Full `npm run typecheck` / `npm run build` အောင်မြင်ကြောင်း မစစ်နိုင်သေးပါက Release Stable ဟု မသတ်မှတ်ရ။ Firebase Emulator၊ Blocking Function Deployment နှင့် Live Login Test များကို သီးခြားလုပ်ရမည်။
