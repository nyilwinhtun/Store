# v3.2.3 Hotfix 1 — Cloud Functions TypeScript Null Guard

## ပြင်ဆင်ရသည့်အကြောင်းရင်း

Cloud Functions build လုပ်ရာတွင် `functions/src/index.ts` ရှိ `event.data` ကို `user` အဖြစ်ယူပြီး `user.uid` နှင့် `user.email` ကို တိုက်ရိုက်ဖတ်ထားသောကြောင့် TypeScript strict mode က `user is possibly 'undefined'` (`TS18048`) ဟု Error ပြခဲ့သည်။

## ပြင်ဆင်ချက်

- `event.data` မရှိပါက `unauthenticated` ဖြင့် fail-closed ပြန်ပိတ်သည်။
- UID သည် non-empty string ဖြစ်ကြောင်း အတည်ပြုပြီးမှ ဆက်လုပ်သည်။
- Email ကို string ဖြစ်မှ normalize လုပ်ပြီး မဟုတ်လျှင် empty string အဖြစ် ကိုင်တွယ်သည်။
- Owner / Cashier authorization logic၊ Business ID၊ Region၊ Firebase configuration နှင့် Firestore Rules ကို မပြောင်းထားပါ။

## ပြင်ဆင်ထားသော Code အပိုင်း

```ts
const user = event.data;

if (!user || typeof user.uid !== 'string' || !user.uid.trim()) {
  throw new HttpsError('unauthenticated', 'Unable to identify the signing-in account.');
}

const uid = user.uid;
const email = (typeof user.email === 'string' ? user.email : '').trim().toLowerCase();
```

## စမ်းသပ်ရန်

```bash

npm --prefix functions run build
```

```bash
npm run typecheck

```
