# Minimart v2.9.2 — Checkout ပစ္စည်းစာရင်း အသေးစိတ်

## ရည်ရွယ်ချက်
ငွေရှင်းပြီးချိန်မှာ Customer နဲ့ Cashier နှစ်ဦးလုံး ယူထားတဲ့ပစ္စည်းစာရင်းကို တစ်နေရာတည်းမှာ တစ်ခါတည်း ပြန်စစ်နိုင်ရန်။ Bluetooth Printer ကို လက်ထဲရောက်မှ Hardware Test သီးခြားလုပ်မည်။

## v2.9.2 ပြင်ဆင်ချက်များ

1. Checkout အောင်မြင်သော Modal တွင် ပစ္စည်းအမည်၊ အရေအတွက်၊ Unit၊ တစ်ခုဈေး၊ ရောင်းချသည့်ဈေးအမျိုးအစား (လက်လီ/လက်ကား) နှင့် လိုင်းစုစုပေါင်း ပြသည်။
2. ပစ္စည်းဖိုး Subtotal၊ Discount (ရှိမှသာ) နှင့် ကျသင့်ငွေ Total ကို Breakdown ပြသည်။
3. Receipt မထုတ်ဘဲ ကျသင့်ငွေပြသည့် Mode မှာလည်း ပစ္စည်းစာရင်းကို မဖျောက်တော့ပါ။
4. Printed Receipt နဲ့ Copy Voucher ထဲတွင်လည်း Quantity + Unit × Unit Price = Line Total ပုံစံဖြင့် ပြသည်။
5. Sale အတွင်း CartItem တစ်ခုချင်းစီ၏ `unit` နဲ့ `quantityMode` ကို snapshot အဖြစ် သိမ်းသည်။ Product Catalog ကို နောက်မှ ပြင်/ဖျက်သော်လည်း ယခင် Sale Receipt ၏ Unit/Quantity formatting မပြောင်းစေရန်ဖြစ်သည်။ Field အသစ်များသည် optional ဖြစ်ပြီး ရှိပြီးသား Sale Data ကို migration မလုပ်လည်း ဖတ်နိုင်သည်။
6. Firebase Login, Firestore Rules, Cloud Sync, Cashier Permission, Stock Transfer နှင့် Sale/Stock calculation logic မပြောင်းထားပါ။

## Checkout စမ်းသပ်ရန်

1. အမျိုးအစားမတူတဲ့ ပစ္စည်း ၂ မျိုး သို့မဟုတ် ၃ မျိုးကို Cart ထဲထည့်ပါ။
2. တစ်ခုချင်း Quantity ပြောင်းပြီး လက်လီ/လက်ကားဈေး ရွေးထားပါ။
3. Discount မပါဘဲ Checkout လုပ်ပြီး Modal ထဲရှိ Item name, quantity, unit, unit price, line total နဲ့ Total ကို စစ်ပါ။
4. Discount တစ်ခု ထည့်ပြီး နောက်တစ်ခါ Checkout လုပ်ပါ။ Discount နဲ့ Total ကိုက်ညီမှု စစ်ပါ။
5. `မထုတ်တော့ဘူး` ကိုရွေးပြီး amount-only view မှာ ပစ္စည်းစာရင်း မပျောက်ကြောင်း စစ်ပါ။
6. နောက်တစ်ခါ Checkout လုပ်ပြီး Print ရွေးပါ။ Print Preview/Receipt ထဲမှာလည်း ပစ္စည်းအသေးစိတ် အတူတူပါကြောင်း စစ်ပါ။
7. Product Catalog ထဲက Product Unit ကို နောက်မှ ပြောင်းပြီး ယခင် Voucher ကို ပြန် Print လုပ်ပါ။ ယခင် Unit snapshot ကို ထိန်းထားကြောင်း စစ်ပါ။
8. အရင် Version က Sale အဟောင်းကို Print/Copy လုပ်ပြီး Unit field မရှိသေးလျှင် လက်ရှိ Product Data မှ fallback လုပ်ကြောင်း စစ်ပါ။

## Test အခြေအနေ

ဒီ Build မှာ UI/Logic ကို Source-level စစ်ဆေးထားသည်။ Real receipt printer hardware မရှိသေးသောကြောင့် Bluetooth pairing နှင့် physical paper output ကို မအတည်ပြုရသေးပါ။ Full npm build ကိုလည်း dependencies install ပြီးမှ အတည်ပြုနိုင်မည်။
