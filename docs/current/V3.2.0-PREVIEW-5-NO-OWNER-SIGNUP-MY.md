# v3.2.0 Preview 5 — Login မှ Owner Account Creation ဖယ်ရှားခြင်း

## ဆုံးဖြတ်ချက်

- Website Root (`/`) တွင် Standalone Login Page ကို ဆက်လက်ပြသမည်။
- Login Screen တွင် Owner Account အသစ်ဖန်တီးရန် Sign Up Button / Link / Form မရှိရ။
- Login Page သည် ရှိပြီးသား Email/Password Account များကို `signInWithEmailAndPassword` ဖြင့်သာ ဝင်ခွင့်ပြုမည်။
- Password Reset ကို ဆက်လက်ထားမည်။
- Login Page မှ `createUserWithEmailAndPassword` နှင့် `updateProfile` အသုံးပြုမှုကို ဖယ်ရှားထားသည်။
- Owner Account ကို လိုအပ်ပါက ခွင့်ပြုထားသော Admin/Firebase Console provisioning နည်းလမ်းဖြင့်သာ စီမံရမည်။
- Owner-only Team Access မှ Cashier Account အသစ်ဖန်တီးနိုင်မှုကို မဖယ်ရှားပါ။ ၎င်းသည် `role: cashier` နှင့် သတ်မှတ် Branch Permission ကိုသာ ဖန်တီးရမည်။

## မပြောင်းထားသောအရာများ

- Firebase Project Config / API Key / Auth Domain
- Firebase Email/Password sign-in API
- AccessBootstrap Owner/Cashier Resolution
- Firestore Rules နှင့် Business Owner UID
- Cashier Team Provisioning Flow
- POS / Sales / Stock / Barcode / Branch Transfer / Finance Logic

## စမ်းသပ်ရန်

- Login Page တွင် Sign Up မရှိရ။
- LoginPage source တွင် `createUserWithEmailAndPassword` မပါရ။
- ရှိပြီးသား Owner/Cashier Account များ Login ဝင်နိုင်ရ။
- မရှိသေးသော Account ဖြင့် Login ဝင်ရန် ကြိုးစားလျှင် မအောင်မြင်ရ။
- Password Reset အလုပ်လုပ်ရ။
- Owner Team Access မှ Cashier Provisioning အလုပ်လုပ်ရ။
- Firebase Project / Owner UID ကို မပြောင်းရ။

## သတိပြုရန်

Login UI မှ Sign Up ဖယ်ရှားခြင်းသည် Firebase Authentication API ကို Project အဆင့်တွင် ပိတ်လိုက်ခြင်း မဟုတ်ပါ။ Email/Password ကို disable လုပ်လိုက်ပါက ရှိပြီးသား Owner/Cashier Login ကိုပါ ပိတ်သွားနိုင်သောကြောင့် ထို Provider ကို မပိတ်ပါနှင့်။ Business Access ကို `ownerUid` နှင့် Firestore Rules က ဆက်လက်ကာကွယ်ရမည်။
