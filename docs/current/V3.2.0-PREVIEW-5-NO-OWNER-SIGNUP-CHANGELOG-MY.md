# Minimart POS v3.2.0 Preview 5 — Login မှ Owner Account Creation ဖယ်ရှားခြင်း

## ပြင်ဆင်မှု

- Login Page မှ Owner Account Create / Sign Up Link, Form, State နှင့် Create Auth API ကို ဖယ်ရှားထားသည်။
- Login Page မှ `createUserWithEmailAndPassword` နှင့် `updateProfile` import/call များ မရှိတော့ပါ။
- ရှိပြီးသား Account များအတွက် `signInWithEmailAndPassword` ကို ဆက်သုံးသည်။
- Password Reset ကို ဆက်ထားသည်။
- Owner Account အသစ်ကို Login Page မှ မဖန်တီးနိုင်တော့ပါ။ လိုအပ်ပါက ခွင့်ပြုထားသော Admin/Firebase Console provisioning လုပ်ငန်းစဉ်ဖြင့်သာ ဆောင်ရွက်ရမည်။
- Owner-only Team Access ထဲမှ Cashier Account Provisioning ကို ဆက်ထားသည်။ ထို Flow သည် `role: cashier` နှင့် Branch တစ်ခုတည်းကိုသာ သတ်မှတ်သည်။
- App Sidebar Version Label နှင့် package version ကို Preview 5 သို့ တိုးထားသည်။

## မပြောင်းထားသောအရာများ

- Firebase Config / Project ID / API Key / Auth Domain
- Email/Password Sign-In Provider နှင့် `signInWithEmailAndPassword`
- Password Reset API
- AccessBootstrap နှင့် Owner/Cashier Business Access Resolution
- Owner UID / Firestore Rules
- Owner-only Team Access Cashier Provisioning
- POS, Sales, Stock, Barcode, Shipment, Finance, Offline Sync Logic

## လုံခြုံရေးမှတ်ချက်

Login Page မှ Sign Up ဖယ်ရှားခြင်းသည် Firebase Email/Password Provider ကို ပိတ်ခြင်းမဟုတ်ပါ။ Provider ကို ပိတ်လိုက်ပါက ရှိပြီးသား Owner/Cashier Login ကိုပါ ထိခိုက်နိုင်သည်။ App ထဲဝင်ခွင့်ကို Business `ownerUid`, Member Role/Branch Mapping နှင့် Firestore Rules က ဆက်လက်ကာကွယ်ရမည်။
