# v3.2.0 Preview 3 — ပြင်ဆင်မှုမှတ်တမ်း

## ရည်ရွယ်ချက်

Branch Transfer ကို သတ်မှတ်ထားသည့် Exception-Based Workflow သို့ ရွှေ့ရန် — ပုံမှန်လက်ခံမှုတွင် Owner Approval မစောင့်ဘဲ Auto Complete ဖြစ်စေပြီး၊ ကွာခြားချက်ရှိမှ Owner Review လုပ်ရန်။

## ပြင်ဆင်ထားသည့်အချက်များ

1. `BranchStockReceivingPage` တွင် ပို့ထားသော Item တစ်ခုချင်း၏ လက်ခံအရေအတွက်သည် ပို့အရေအတွက်နှင့် တိတိကျကျကိုက်ညီပြီး ပျက်စီးအရေအတွက် သုညဖြစ်သည့်အခါ Auto Complete လမ်းကြောင်းကို ရွေးထားသည်။
2. Batch Allocation စာရင်းပြည့်စုံမှု၊ Destination Product များထပ်နေမှု၊ Product Stock နှင့် Batch Stock ကိုက်ညီမှု၊ Unit Barcode Tracking ရှိ/မရှိ၊ Quantity Mode ကို Preflight စစ်ထားသည်။
3. Auto Complete Local Plan တွင် Destination Product ID, Stock Before/After နှင့် Destination Batch IDs ကို ထိန်းသိမ်းထားသည်။
4. `src/lib/branchShipmentAutoComplete.ts` အသစ်ထည့်ပြီး Cloud Shipment ကို `dispatched` အခြေအနေမှသာ လက်ခံကာ Destination Product, Destination Stock Batch နှင့် Shipment `approved/auto` ကို Firestore Transaction တစ်ခုတည်းဖြင့် သိမ်းရန် ချိတ်ဆက်ထားသည်။
5. Cloud Commit မအောင်မြင်မှုကို သေချာသိနိုင်လျှင် Local Optimistic Change ကို rollback လုပ်ပြီး လက်ရှိ Owner Review Receipt လမ်းကြောင်းသို့ ပြန်ပို့ထားသည်။ Commit ရလဒ် မသေချာပါက ထပ်မံ Submit မလုပ်ရန် သတိပေးထားသည်။
6. Firestore Rules တွင် Stock Receiver အတွက် Shipment တစ်ခုနှင့် Line/Batch Allocation တစ်ခုချင်း ချိတ်ဆက်ထားသော Product/Batch Create/Update ကိုသာ ခွင့်ပြုရန် helper functions ထည့်ထားသည်။ Generic Cashier Product/Batch Write Permission မပေးထားပါ။
7. Owner Shipment Management တွင် Auto Complete နှင့် Owner-approved Completion ကို သီးခြားဖော်ပြထားသည်။
8. Store ထဲက Destination Product Matching ကို empty SKU/Barcode တူညီမှုကြောင့် မသက်ဆိုင်သော Product များကို match ဖြစ်စေနိုင်သည့် ပြဿနာကာကွယ်ရန် ပြင်ထားသည်။
9. Legacy Shipment တွင် explicit `quantityMode` မရှိပါက ခန့်မှန်း Auto Complete မလုပ်ဘဲ Owner Review သို့ ပြန်ပို့ထားသည်။

## မပြောင်းထားသည့်အပိုင်းများ

- Firebase Config / Authentication / Login validation
- Business Access / Branch membership logic
- လက်ရှိ Source Shipment Cloud Commit logic
- CashierAutoSync / OwnerAutoSync
- POS Sales implementation နှင့် Finance workflows

## ကန့်သတ်ချက်

- Unit Barcode ပါသော Product ကို ဒီ Preview တွင် Quantity-only Branch Transfer မလုပ်နိုင်ပါ။ Barcode Unit Transfer ကို နောက်အဆင့်သီးခြားလုပ်ရမည်။
- Auto Complete သည် Online အခြေအနေမှာသာ လုပ်ဆောင်သည်။
- Full Vite Build၊ Rules Emulator၊ Multi-device Live Regression မအောင်မြင်သေးပါ/မစမ်းသပ်ရသေးပါ။
