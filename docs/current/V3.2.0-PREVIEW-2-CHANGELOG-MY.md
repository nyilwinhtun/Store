# v3.2.0 Preview 2 — ပြင်ဆင်မှုမှတ်တမ်း

## ပြင်ဆင်ပြီး

### 1. Owner Dashboard: All Branches / Individual Branch
- Owner အတွက် Dashboard အတွင်း `ဆိုင်အားလုံး (All Branches)` နှင့် Branch တစ်ခုချင်းစီကို ရွေးကြည့်နိုင်သည်။
- All Branches ရွေးထားလျှင် ယနေ့ရောင်းအား၊ ခန့်မှန်းအမြတ်၊ Product စာရင်းအရေအတွက်၊ Low Stock သတိပေးချက်၊ Sales Trend နှင့် နောက်ဆုံးအရောင်းများကို ခြုံငုံပြသည်။
- Branch Card တစ်ခုချင်းစီတွင် ယနေ့ရောင်းအား၊ အရောင်းအကြိမ်ရေ၊ Stock ရှိသော Product အရေအတွက်နှင့် Low Stock အရေအတွက်ကို ပြသည်။
- Dashboard branch filter သည် Topbar ၏ Active Branch ကို မပြောင်းပါ။ POS / Inventory / Finance အတွက် လက်ရှိ branch context ကို မထိခိုက်စေပါ။
- Cashier အတွက် All Branches filter မပြပါ။ သူ့ရဲ့ assigned branch data သာ ပြသည်။

### 2. Branch Shipment Exception Visibility
- Owner Shipment History တွင် ပို့ထား/လက်ခံထား အရေအတွက်ကို နှိုင်းယှဉ်ပြီး mismatch သို့မဟုတ် damaged quantity ရှိပါက Exception အဖြစ် သတ်မှတ်ပြသည်။
- Shipment Summary တွင် လက်ခံရန်ကျန်၊ အရေအတွက်ကိုက်ညီ၊ Owner Review လိုအပ် စာရင်းများကို သီးခြားပြသည်။
- Quantity မကိုက်ညီသော shipment အတွက် Owner Review ခလုတ်စာသားကို သီးခြားပြသည်။

## မပြောင်းထားသော အရေးကြီးအပိုင်းများ
- Firebase Authentication, Login Validation, Firebase Config / API Keys မပြောင်းထားပါ။
- Firestore Security Rules မပြောင်းထားပါ။
- POS Sale Transaction / Stock Update / Offline Queue မပြောင်းထားပါ။
- Branch Shipment Dispatch Cloud Transaction နှင့် လက်ရှိ Receive / Owner Commit data flow မပြောင်းထားပါ။
- လက်ရှိ Status များနှင့် Database Schema အသစ် မထည့်ထားပါ။

## လုပ်ငန်းစဉ်အပေါ် သတိပြုရန်
User ရွေးထားသော policy သည် ပုံမှန်လက်ခံမှုကို Auto Complete လုပ်ပြီး discrepancy ရှိမှ Owner Review လုပ်ရန် ဖြစ်သည်။ Preview 2 တွင် Exception Detection နှင့် Dashboard Visibility ကိုသာ ထည့်ထားသည်။ လက်ရှိ Firestore Rules က Cashier ကို Shipment Receipt Document တစ်ခုသာ update ခွင့်ပြုပြီး Destination Product / Stock Batch ကို တစ်ပြိုင်နက် ပြောင်းခွင့်မပေးသေးပါ။ ထို့ကြောင့် Exact-match shipment များအတွက် Owner Commit ကို ယာယီဆက်လက်လိုအပ်သည်။ Security Rules နှင့် atomic Cloud transaction ကို Emulator ဖြင့် သေချာစမ်းသပ်ပြီးမှ Auto Complete ကို သီးခြား Preview အဖြစ် ဖွင့်ရမည်။

## Verification
- Source ထဲရှိ TypeScript / TSX ဖိုင် ၄၀ ခုလုံးကို TypeScript Parser ဖြင့် စစ်ဆေးပြီး Syntax Error ၀ ခု တွေ့ရှိသည်။
- `npm install` ကို ကြိုးစားခဲ့သော်လည်း လုပ်ဆောင်ချိန်ကုန်ဆုံးသွားပြီး Dependency များ မရရှိခဲ့ပါ။
- ထို့ကြောင့် Full Vite Build၊ Full Type Check နှင့် Firebase Emulator Test မပြီးသေးပါ။
- Production သို့ မတင်ရသေးပါ။
