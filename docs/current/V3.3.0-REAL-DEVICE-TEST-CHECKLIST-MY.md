> **အခြေအနေ — NOT RUN.** ဤစာရင်းကို Physical Device များတွင် ဖြေဆိုရန်

## 7. Bluetooth Thermal Printer

> App ထဲမှ Direct Bluetooth Pairing မပါပါ။ Printer ကို Device OS တွင်
> Pair/Add လုပ်ထားရပြီး Print Service က Printer ကို မြင်ရပါမည်။

- [ ] Printer ကို OS Bluetooth Settings တွင် Pair လုပ်နိုင်သည်။
- [ ] POS/Settings → Test Print ဖြင့် 58 mm စက္ကူ ထုတ်နိုင်သည်။
- [ ] 80 mm စက္ကူ ထုတ်နိုင်သည်။
- [ ] Receipt တွင် ဆိုင်အမည်၊ Voucher No၊ ရက်စွဲ/အချိန်၊ ပစ္စည်း၊
      အရေအတွက်၊ ဈေးနှုန်း၊ Total၊ ငွေရှင်းနည်း၊ ပြန်အမ်းငွေ ပါသည်။
- [ ] Myanmar Unicode စာလုံးများ မပျက်မကွဲ ထုတ်နိုင်သည်။
- [ ] MMK ပမာဏတွင် ကော်မာ (ဥပမာ `1,500 MMK`) မှန်ကန်သည်။
- [ ] ရှည်သော Product အမည်များ မဖြတ်တောက်ပဲ Wrap ဖြစ်သည်။
- [ ] Receipt အောက်ခြေစာသား ပါသည်။
- [ ] Print ပြီးနောက် စက္ကူ ဖြတ်တောက်မှု မှန်ကန်သည်။
- [ ] တူညီသော Voucher ကို ပြန်ထုတ်နိုင်သည်။
- [ ] Printer ပြတ်တောက်လျှင် App သည် Crash မဖြစ်ပဲ Print Dialog Error ပြသည်။
- [ ] ဖုန်း Screen Lock ပြီး ပြန်ဖွင့်လျှင် Printer ချိတ်ဆက်မှု ပြန်ရသည်။

- [ ] Void ပြီးနောက် နောက်ထပ် Sale တစ်ခု လုပ်နိုင်သည် (Stock Batch Coverage)။
- [ ] Void ကို နှစ်ကြိမ် နှိပ်လျှင် Stock နှစ်ကြိမ် မတိုးပါ။
- [ ] Cashier သည် အခြား Cashier ၏ Sale/Expense/Settlement ကို မမြင်ရပါ။
- [ ] Cashier သည် အခြားဆိုင်ခွဲ Stock/Sales ကို မမြင်ရပါ။
- [ ] Cashier က Void ကို ကိုယ်တိုင် မလုပ်နိုင်ပဲ Owner ထံ တောင်းဆိုရသည်။
- [ ] Shift ပိတ်ပြီးနောက် Cash Movement ထပ်မံ မလုပ်နိုင်ပါ။

- [ ] Activity Log တွင် Sale/Void/Stock/Payment လုပ်ဆောင်ချက်များ ပါသည်။
