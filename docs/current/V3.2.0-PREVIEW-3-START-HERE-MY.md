# Minimart POS v3.2.0 — Preview 3 (Branch Transfer Auto Complete)

ဒီ ZIP သည် သီးခြား Preview ဖြစ်ပြီး Production သို့ တန်းမတင်ရသေးပါ။ မူရင်း Project နှင့် Firebase Production Data ကို မပြောင်းပါ။

## စမ်းသပ်ရန်

1. ZIP ကို ဖြည်ပါ။
2. Project Folder ထဲတွင် Terminal ဖွင့်ပါ။
3. `npm install` လုပ်ပါ။
4. `npm run build` အောင်မြင်ကြောင်း စစ်ပါ။
5. `npm run dev` ဖြင့် Local Preview ဖွင့်ပါ။
6. `V3.2.0-PREVIEW-3-TEST-PLAN-MY.md` အတိုင်း Test Firebase Project / Emulator မှာ စမ်းပါ။

## ဒီ Preview ရဲ့ အဓိကပြောင်းလဲမှု

- ပို့ထားသည့် အရေအတွက်အပြည့် လက်ခံပြီး ပျက်စီးမှုမရှိသည့်အခါ Cloud Transaction တစ်ခုတည်းဖြင့် Destination Product, Stock Batch နှင့် Shipment Auto Complete ကို သိမ်းရန်။
- အရေအတွက်ကွာခြားမှု/ပျက်စီးမှုရှိသည့်အခါ Destination Stock မတိုးဘဲ Owner Review လမ်းကြောင်းကို ဆက်သုံးရန်။
- Receiver အတွက် Firestore Permission ကို Shipment နှင့် ချိတ်ထားသော Destination Product/Batch Write များအပေါ်သာ ကန့်သတ်ရန်။
- Unit Barcode Tracking ရှိပြီးသား Product ကို Quantity-only Transfer မလုပ်နိုင်အောင် ဆက်လက်ကာကွယ်ရန်။

## လက်ရှိအတည်ပြုထားသော ကန့်သတ်ချက်

- Full Vite Build နှင့် Firestore Emulator Rules Test မအောင်မြင်သေး/မလုပ်ရသေးပါ။
- Auto Complete သည် Online ဖြစ်ရန်လိုသည်။
- Unit-level Barcode Transfer (Barcode တစ်ခုချင်း Branch လွှဲပြောင်းခြင်း) ကို ဒီ Preview မှာ မထည့်ရသေးပါ။ ထို Product များအတွက် Quantity-only Transfer ကို Block လုပ်ထားသည်။
- `firestore.rules` ကို Production မှာ မ Publish လုပ်ရသေးပါ။

အသေးစိတ်အတွက် `V3.2.0-PREVIEW-3-RELEASE-GATE-MY.md` ကို ဖတ်ပါ။
