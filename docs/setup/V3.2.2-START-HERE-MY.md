# v3.2.2 — စတင်အသုံးပြုရန်

## 1. မူရင်း Version ကို ထိန်းသိမ်းပါ

v3.2.1 ZIP ကို မဖျက်ပါနှင့်။ v3.2.2 ကို Folder အသစ်တစ်ခုထဲ Extract လုပ်ပါ။ Production Firebase ကို Test မလုပ်မီ Backup ယူပါ။

## 2. Install / Build

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

`functions/` အတွက် သီးခြား Install / Build လုပ်ရန်—

```bash
npm --prefix functions install
npm --prefix functions run build
```

## 3. Login စမ်းသပ်ရန်

- Website ကိုဖွင့်လျှင် Login Page ပေါ်ရမည်။
- အရင် Owner Email / Password ဖြင့် Login ဝင်ပါ။
- Owner Dashboard သို့ ဝင်နိုင်ရမည်။
- Active Cashier ဖြင့်ဝင်လျှင် တာဝန်ကျ Branch POS ကိုသာ မြင်ရမည်။
- Disabled / unassigned / unknown role Account များကို Workspace ထဲ မဝင်စေရ။
- Website နှင့် Team Access Panel တွင် Public Account Creation ခလုတ် မရှိရ။

## 4. Cashier အသစ် Provision လုပ်ရန်

Firebase Console Admin က Authentication User ကို ကြိုတင်ဖန်တီးပြီး UID ကိုယူပါ။ Owner App ထဲက Team Access Panel မှ Email, UID နဲ့ Branch တစ်ခုကို ချိတ်ဆက်ပါ။ Member Verify အောင်မြင်ပြီးမှ Cashier Login စမ်းပါ။

## 5. Firebase Server Security

App UI မှ Sign Up ဖယ်ရှားထားခြင်းသည် Firebase Auth API ကို တခြား Client မှ ခေါ်ခြင်းကို တစ်ခုတည်းနဲ့ မပိတ်နိုင်ပါ။ `docs/firebase/ACCOUNT-ACCESS-SECURITY-MY.md` အတိုင်း Identity Platform Upgrade၊ Billing/Functions prerequisites၊ Firestore Rules နှင့် Cloud Functions ကို Test Project/Emulator မှာ စမ်းသပ်ပြီးမှ Production သို့ သီးခြား Deploy လုပ်ပါ။ Production မတင်မီ Test Project ဖြင့် အရင်စမ်းပါ။

## 6. Documentation

Documentation အားလုံးကို `docs/` ထဲမှာ စုစည်းထားသည်။ Root တွင် `README.md`, `package.json`, Vite / TypeScript / Firebase Configuration နှင့် Source Folders များသာ ထားသည်။
