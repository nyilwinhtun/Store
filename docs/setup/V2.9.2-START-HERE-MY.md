# Minimart v2.9.2 — စတင်အသုံးပြုရန်

1. လက်ရှိ Laptop နှင့် Phone နှစ်ခုလုံးမှ Owner JSON Backup ထုတ်ပါ။
2. ZIP ဖြည်ပြီး GitHub Repository ထဲရှိ Project ဖိုင်များကို Update လုပ်ပါ။
3. `npm install` ပြီး `npm run build` ဖြင့် Build အောင်မြင်ကြောင်း စစ်ပါ။
4. GitHub Actions Deploy အောင်မြင်မှ Phone နှင့် Laptop မှာ Update လုပ်ပါ။
5. Test Sale တစ်ခုဖန်တီးပြီး Checkout Result Modal ထဲမှာ ပစ္စည်းအမည်၊ Qty/Unit၊ တစ်ခုဈေး၊ လိုင်းစုစုပေါင်း၊ Subtotal၊ Discount နဲ့ Total ကို ပြန်စစ်ပါ။
6. No Print နဲ့ Print နှစ်မျိုးလုံး စမ်းပါ။ Printer hardware မရှိသေးပါက Print Preview / Save as PDF ဖြင့်သာ UI ကို စမ်းနိုင်သည်။
7. Bluetooth Printer စမ်းသပ်မှုကို Printer Model ရရှိပြီး လက်တွေ့ချိတ်ဆက်နိုင်ချိန်မှ ဆက်လုပ်ပါ။

## Data Safety
- Firebase Authentication / API config မပြောင်းပါ။
- Cloud Sync / Firestore Rules မပြောင်းပါ။
- Cashier Permission / Branch Assignment မပြောင်းပါ။
- Stock Transfer / POS stock calculation မပြောင်းပါ။
- `CartItem.unit` နှင့် `CartItem.quantityMode` သည် optional snapshot fields အသစ်သာ ဖြစ်သည်။ Old Sales records တွေမှာ field မရှိလည်း ပြသရာတွင် Product data မှ fallback လုပ်သည်။
