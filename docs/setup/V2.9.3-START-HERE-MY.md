# Minimart v2.9.3 — စတင်အသုံးပြုရန်

1. မတင်မီ Laptop/Phone Owner Device တစ်ခုချင်းစီမှ JSON Backup ထုတ်ပါ။ LocalStorage နှင့် IndexedDB မရှင်းပါနှင့်။
2. ZIP ကို Folder အသစ်အဖြစ် ဖြည်ပြီး VS Code မှာ ဖွင့်ပါ။ မိမိအသုံးပြုနေသော `.env` ကို လုံခြုံစွာ ပြန်ထည့်ပါ။
3. Terminal မှာ `npm install` လုပ်ပါ။
4. `npm run typecheck` ပြီးနောက် `npm run build` နှစ်ခုလုံး အောင်မြင်ရမည်။
5. `npm run dev -- --host --port 5173 --strictPort` ဖြင့် စမ်းပါ။
6. Product အသစ်ထည့်ရာတွင် Barcode Field မှာ HID Scanner သို့မဟုတ် Camera Scan အသုံးပြုပါ။ Existing Product များအတွက် Inventory → Edit ကနေ Barcode ထည့်နိုင်သည်။
7. POS မှာ Search Box ကို Focus လုပ်ပြီး HID Scanner နဲ့ ဖတ်ပါ။ Scanner ကို Enter suffix ပို့ရန် configure လုပ်ထားရမည်။ Camera ခလုတ်မှ Phone Scan လုပ်နိုင်သည်။
8. ကုန်ရောက်လက်ခံရေးတွင် Barcode ထည့်ပြီး ရှိပြီးသား Product ကို သတ်မှတ်နိုင်သည်။ မသိသေးသော Barcode ဆိုလျှင် ပစ္စည်းအမည် ဖြည့်ပြီး Save လုပ်ပါ။
9. HTTPS Deployment မှာ Phone Camera Permission Allow လုပ်ပါ။
10. Test Sales, Stock, Cloud Sync အောင်မြင်မှ GitHub ကို Deploy လုပ်ပါ။

အသေးစိတ်စမ်းသပ်ရန် `V2.9.3-BARCODE-AND-CAMERA-SCAN-MY.md` ကို ဖတ်ပါ။ Bluetooth Printer Hardware ကို မစမ်းရသေးပါ။ Bluetooth Barcode Scanner လည်း HID Keyboard mode အတွက် စက်ပေါ်တွင် Pair စမ်းသပ်ရန် လိုသေးသည်။
