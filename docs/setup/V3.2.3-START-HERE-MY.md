# v3.2.3 — စတင်အသုံးပြုရန်

## 1. မူရင်း Version ကို ထိန်းသိမ်းပါ

v3.2.2 ZIP ကို မဖျက်ပါနှင့်။ v3.2.3 ကို Folder အသစ်ထဲ Extract လုပ်ပါ။ Live Firebase မှာ စမ်းသပ်မည့်အစား Emulator / Test Project ကို အသုံးပြုပါ။

## 2. Install နှင့် Static Check

```bash
npm install
npm run check:security
npm run typecheck
npm run build
```

## 3. Firestore Rules Test

Java Runtime နှင့် Firebase CLI တပ်ဆင်ပြီး—

```bash
npm install -g firebase-tools
npm run test:rules
```

## 4. Cloud Functions Build

```bash
npm --prefix functions install
npm --prefix functions run build
```

## 5. Production ကို မတင်သေးပါနှင့်

Firebase Console တွင် Business `ownerUid` ကို အရင်အတည်ပြုပါ။ Identity Platform Upgrade၊ Blocking Trigger Register နှင့် Production Deploy ကို Test Project မှာ QA အောင်မြင်ပြီး၊ Project Owner အတည်ပြုပြီးမှသာ လုပ်ပါ။ အသေးစိတ်ကို `docs/firebase/V3.2.3-SECURITY-DEPLOYMENT-MY.md` တွင်ကြည့်ပါ။

မှတ်ချက် — ဒီ Candidate ထုတ်ချိန်မှာ Static Preflight နှင့် Source Syntax Check သာ အောင်မြင်ထားသည်။ Firestore Emulator Test နှင့် Full Vite Build ကို သင့်စက် သို့မဟုတ် GitHub Actions တွင် အောင်မြင်ကြောင်း စစ်ပြီးမှ Release အဖြစ် သတ်မှတ်ပါ။
