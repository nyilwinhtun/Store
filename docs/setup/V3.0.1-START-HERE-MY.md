# v3.0.1 စတင်အသုံးပြုနည်း

## Update မလုပ်မီ

1. Laptop နှင့် Phone မှ JSON Backup ထုတ်ပါ။
2. လက်ရှိ GitHub Repository/Folder ကို မဖျက်ဘဲ ZIP အသစ်ကို Folder သီးခြားဖြည်ပါ။
3. `.env` အသုံးပြုထားပါက မူလ Project မှ လိုအပ်သော Config ကို လုံခြုံစွာ ပြန်ထည့်ပါ။ Firebase Config သည် `minimart-production` ကိုပဲ ညွှန်ရပါမည်။
4. `firestore.rules` ကို ဒီ Version ကြောင့် အစားထိုးရန် မလိုပါ။ လက်ရှိ Rules ကို မပြောင်းပါနှင့်။

## Install / Build

Project Folder ထဲ Terminal ဖွင့်ပြီး—

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

Typecheck နှင့် Build အောင်မြင်မှ Deploy လုပ်ပါ။

## ဖုန်း POS စမ်းသပ်ရန်

1. Cashier အကောင့်ဖြင့် ဝင်ပြီး သတ်မှတ်ထားသော Branch မှန်ကြောင်း စစ်ပါ။
2. POS မှာ Product Card ကို တစ်ချက်နှိပ်ပါ။ Cart ထဲ Product ဝင်လာကြောင်း စစ်ပါ။
3. Cart ရှိ `− / +` ဖြင့် အရေအတွက်ပြောင်းပါ။ Archive ခလုတ်ဖြင့် Not Buying List ထဲသို့ ခဏဖယ်ပြီး ပြန်ထည့်ခြင်းကို စမ်းပါ။
4. Checkout နှိပ်ပါ။ Customer တကယ်ပေးသော Cash Received ပမာဏကို ထည့်ပါ။ ငွေအတိအကျပေးလျှင် “ကျသင့်ငွေအတိအကျ ထည့်မယ်” ကိုနှိပ်နိုင်ပါတယ်။ စမ်းသပ်ရန် Total ထက်နည်းသော ပမာဏ (ဥပမာ Total 28,000 ဖြစ်လျှင် 20,000) ထည့်ပါ။
5. 8,000 MMK လိုနေကြောင်း သတိပေးပြီး “ပစ္စည်းလျှော့ / Cart ပြန်ပြင်မယ်” လုပ်ဆောင်ချက် အလုပ်လုပ်ကြောင်း စစ်ပါ။ ဒီအဆင့်မှာ Sale မသိမ်းရ၊ Stock မလျှော့ရပါ။
6. Cart ထဲက Product Qty လျှော့/ဖယ်ပြီး Checkout ပြန်ဝင်ပါ။ Cash Received တန်ဖိုးကို ဆက်ထိန်းထားပြီး လိုအပ်သလို ပြန်တွက်ကြောင်း စစ်ပါ။
7. Cash Received သည် Total ထက် ညီ သို့မဟုတ် ပိုလျှင် Confirm လုပ်ပါ။ Sale တစ်ခုသာ သိမ်းပြီး Stock တစ်ကြိမ်သာ လျှော့ရပါမည်။
8. ငွေပိုပေးထားပါက Change မှန်ကန်ကြောင်း၊ Checkout Result, Receipt နှင့် Sales CSV တွင် Cash Received/Change မှန်ကြောင်း စစ်ပါ။
9. Credit Payment ကိုလည်း စမ်းပါ—Customer အမည်လိုအပ်ချက်နှင့် Due Amount အရင်လို အလုပ်လုပ်ရပါမည်။

## Layout စမ်းသပ်ရန်

- Product Grid အတွင်း Scroll လုပ်နိုင်ရမည်။ Product Card ကို Tap လုပ်လျှင် Cart ထဲဝင်ရမည်။
- Cart Items အတွင်း သီးခြား Scroll လုပ်နိုင်ရမည်။
- Checkout Button သည် Android Bottom Navigation/OS gesture area အောက်တွင် မဖြတ်ကျန်ရပါ။
- Not Buying List ကို ပိတ်ထားလျှင် Cart အတွက် နေရာပိုရရမည်။
- Laptop/Desktop Layout မပြောင်းလဲရပါ။

## မပြောင်းရမည့်အရာ

- Firebase Project ID, Owner UID, Business ID
- Firestore Rules
- `localStorage` / IndexedDB Data ကို Reset မလုပ်ပါနှင့်။
- Cloud Bootstrap / Initial Snapshot ကို ထပ်မနှိပ်ပါနှင့်။
- Cashier Cloud Sales Queue ထဲ Pending Sale ရှိနေပါက Browser Data မရှင်းပါနှင့်။
