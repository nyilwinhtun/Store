# စတင်အသုံးပြုရန် — Minimart POS v3.2.1 Shared Pricing

1. မူရင်း v3.1.5 / v3.1.6 / v3.2.0 ဖိုင်များကို မဖျက်ပါနှင့်။
2. ZIP ကို Folder အသစ်တစ်ခုထဲ Extract လုပ်ပါ။
3. Production Data မဟုတ်သော Test Firebase Project သို့မဟုတ် Local Test Data ဖြင့်သာ စတင်ပါ။
4. Owner JSON Backup နှင့် Firestore Export ယူပါ။
5. `npm install` ပြီး `npm run typecheck` နှင့် `npm run build` စမ်းပါ။
6. `npm run dev` ဖြင့် ဖွင့်ပါ။ Owner Account ဖြင့် Login ဝင်ပါ။
7. `မျှဝေဈေးနှုန်း` ကို ဖွင့်ပါ။ အဲဒီစာမျက်နှာရှိ Owner Cloud Sync သည် Synced ဖြစ်ပြီး Internet ချိတ်ထားမှသာ Create / Update / Attach / Unlink လုပ်ပါ။
8. Branch ၂ ခုမှ တူညီသော Product တစ်မျိုးစီ ရွေးကာ Price Group ဖန်တီးပါ။
9. Product စာရင်း၊ Stock၊ Cost Price များ Branch သီးခြားဖြစ်နေကြောင်း စစ်ပါ။
10. Group ဈေးနှုန်းပြောင်းပါ။ Product Mirrors နှစ်ဆိုင်လုံး Update ဖြစ်ကြောင်း၊ Sale အဟောင်း၏ Unit Price မပြောင်းကြောင်း စစ်ပါ။
11. Cashier Login ဖြင့် Price Group Page မမြင်ရကြောင်း၊ မိမိခွင့်ပြု Branch မှ Product Mirror Price ကိုသာ ရရှိကြောင်း စမ်းပါ။
12. Branch တစ်ခု Archive လုပ်ထားပြီး Shared Price Group ကျန်နေသည့်အခါ Owner သည် Pricing Page ကို ဆက်ဖွင့်နိုင်ကြောင်း စမ်းပါ။
13. `V3.2.1-TEST-PLAN-MY.md` နှင့် `V3.2.1-SHARED-PRICING-MY.md` ကို လိုက်နာပါ။

Production Firestore Rules ကို Emulator Test မအောင်မြင်မီ Deploy မလုပ်ပါနှင့်။ ဒီ Build သည် Candidate ဖြစ်ပြီး Live Firebase ကို စမ်းသပ်ထားခြင်း မရှိပါ။
