# v3.2.0 Phase 1 — စတင်အသုံးပြုရန်

## ရည်ရွယ်ချက်
Owner တစ်ယောက်သည် ဆိုင်ခွဲအားလုံးကို တစ်နေရာတည်းတွင် ကြည့်ပြီး သက်ဆိုင်ရာ Branch Dashboard သို့ အလွယ်တကူ ဝင်နိုင်ရန်။

## လုပ်ဆောင်ချက်များ
- Multi-branch Owner landing page: ဆိုင်အားလုံး Overview
- Single-branch Owner landing page: မူလ Dashboard
- Branch card မှ Branch Dashboard သို့ဝင်ခြင်း
- Header Branch Selector မှ ဆိုင်အားလုံး / Branch တစ်ခုရွေးခြင်း
- Branch Management မှ Branch ဖွင့်ခြင်း
- Branch ပြောင်းချိန် Cart အတည်ပြုခြင်းနှင့် Sale persistence အခြေအနေကို ကာကွယ်ခြင်း

## အချက်အလက်ဖတ်ရှုရာတွင် သတိပြုရန်
Overview သည် လက်ရှိ Store ထဲ ရရှိထားသော Branch-scoped records မှ တွက်ချက်ပြသသည့် Read-only စာမျက်နှာဖြစ်သည်။ Owner ရဲ့ Cloud Sync လုပ်ငန်းစဉ်ကနေ မရရှိသေးသော Data ကို အလိုအလျောက် Cloud ကနေ ထပ်မံဆွဲယူပေးတဲ့ အသစ်သော Query Engine မဟုတ်ပါ။ Finance Balance များကို Branch များပေါင်းပြီး မပြထားပါ။

## Build
```bash
npm install
npm run typecheck
npm run build
```

Live Firebase နဲ့ Production ဆိုင်မသုံးမီ Test Plan ကို အောင်မြင်စွာ ဖြတ်သန်းပါ။
