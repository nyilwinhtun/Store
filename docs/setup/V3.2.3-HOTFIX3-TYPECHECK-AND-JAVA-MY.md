# v3.2.3 Hotfix 3 — Typecheck & Java Setup

## ဘာပြင်ထားသလဲ

- `usePosStore.ts` မှာ Zustand `persist.getOptions().name` ကို TypeScript က `string | undefined` လို့ သတ်မှတ်နိုင်တဲ့အတွက် stable storage key fallback ထည့်ထားပါတယ်။
- မူလ LocalStorage key `minimart-pos-data-v1` ကို မပြောင်းပါ။ ရှိပြီးသား POS Data ကို key အသစ်သို့ ရွှေ့ခြင်း မရှိပါ။
- Firebase Emulator အတွက် Mac မှာ Java JDK 21 လိုအပ်ပါတယ်။ Firebase CLI v15 က Java 21 အောက်ကို မထောက်ပံ့တော့တာကြောင့် Java 21 သို့မဟုတ် ပိုမြင့်တဲ့ JDK ကို တပ်ဆင်ပါ။

## 1. TypeScript Hotfix စမ်းသပ်ခြင်း

Project Root ထဲမှာ Terminal ဖွင့်ပြီး:

```bash
npm run typecheck
npm run build
```

Typecheck အောင်မြင်မှ Build ကို ဆက်လုပ်ပါ။

## 2. macOS မှာ Java 21 တပ်ဆင်ခြင်း

Homebrew ရှိပါက:

```bash
brew install --cask temurin@21
```

Terminal ကို ပိတ်ပြီး ပြန်ဖွင့်ပါ။ ထို့နောက်:

```bash
java -version
/usr/libexec/java_home -V
```

Java 21 ပြသရပါမယ်။ မပြသရင် လက်ရှိ Terminal Session အတွက်:

```bash
export JAVA_HOME=$(/usr/libexec/java_home -v 21)
export PATH="$JAVA_HOME/bin:$PATH"
java -version
```

Homebrew မရှိပါက Eclipse Temurin 21 ကို https://adoptium.net/ မှ macOS installer ဖြင့် တပ်ဆင်နိုင်ပါတယ်။

## 3. Firestore Rules Emulator Test

Java တပ်ဆင်ပြီးနောက် Project Root မှာ:

```bash
npm run test:rules
```

ဒီ Command က Firestore Emulator ကို စတင်ပြီး Rules Test ကို run ပါမယ်။ ဒီ Test ဟာ Demo Project ID ကိုသာ သုံးဖို့ သတ်မှတ်ထားပြီး Live Firebase Project ကို မရည်ရွယ်ပါ။
