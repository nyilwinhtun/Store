# Minimart v2.9.1 — စတင်အသုံးပြုရန်

## Update မလုပ်ခင်

1. Owner Device နဲ့ Cashier Device တွေမှာ JSON Backup ထုတ်ပါ။
2. လက်ရှိ Project ကို Folder သီးခြားတစ်ခုအဖြစ် Backup လုပ်ထားပါ။
3. ZIP ကို Folder အသစ်အဖြစ် ဖြည်ပြီး VS Code နဲ့ဖွင့်ပါ။
4. Firebase Config / `.env` ကို မူလ Project အတိုင်း ထည့်ထားပါ။

## Mac Terminal

```bash
npm install
npm run typecheck
npm run build
npm run dev -- --host --port 5173 --strictPort
```

Build အောင်မြင်မှ GitHub Repository ကို update/push လုပ်ပါ။ GitHub Actions Deploy အောင်မြင်ကြောင်း စစ်ပါ။

## v2.9.1 တွင် စမ်းရန်

1. POS မှာ receipt width ကို 58mm သို့မဟုတ် 80mm ရွေးပါ။
2. `Test Print` နှိပ်ပြီး Browser/System Print Dialog ပေါ်မပေါ် စစ်ပါ။
3. Print Dialog မှာ သင့် Printer/Print Service ကို ရွေးပါ။
4. Test slip ပေါ်က စက္ကူအကျယ်၊ မြန်မာစာ၊ ဖြတ်တောက်မှု စစ်ပါ။
5. Sale တစ်ခု Checkout လုပ်ပါ။
6. `Printer နဲ့ Receipt ထုတ်မယ်` နဲ့ `မထုတ်တော့ဘူး · ပမာဏပဲကြည့်မယ်` နှစ်မျိုးလုံး စမ်းပါ။
7. No Print ကိုရွေးလျှင် Total-only screen ဆက်ပေါ်ရမည်။ `ပြီးပါပြီ` နှိပ်မှ ပိတ်ရမည်။
8. Sales History မှ Voucher ပြန် Print စမ်းပါ။

## Bluetooth အကြောင်း

လက်ရှိ Version သည် Browser/System Print ကို အသုံးပြုသည်။ Bluetooth printer တစ်လုံးတည်းဆိုလျှင် OS Print Service က အသိအမှတ်ပြုပေးထားမှ Print Dialog ထဲတွင် ပေါ်မည်။ App အတွင်း Direct Bluetooth Pairing ကို မထည့်ရသေးပါ။ Android, macOS နဲ့ iOS တို့၏ printer support ကွာခြားမှုနှင့် Hardware စမ်းသပ်ရန်အချက်အလက်ကို `V2.9.1-RECEIPT-PRINT-CHOICE-MY.md` မှာ ဖတ်ပါ။

## မထိထားသောအရာများ

Firebase Login, Firebase API Config, Firestore Rules, Cloud Sync, POS Data Structure, Cashier Permissions, Stock Transfer ကို မပြောင်းထားပါ။ Printer Paper Width preference တစ်ခုသာ Device-local ဖြစ်သည်။
