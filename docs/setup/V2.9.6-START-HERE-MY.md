# Minimart v2.9.6 — စတင်အသုံးပြုရန်

1. လက်ရှိ v2.9.5 Project နှင့် LocalStorage Data ကို JSON Backup ထုတ်ပါ။
2. ZIP ကို Folder အသစ်ထဲ ဖြည်ပါ။ လက်ရှိ Project ကို အရင် overwrite မလုပ်ပါနှင့်။
3. `npm install` ပြီး `npm run typecheck` နှင့် `npm run build` လုပ်ပါ။
4. Build အောင်မြင်မှ Local test သို့မဟုတ် သီးခြား staging deploy လုပ်ပါ။
5. Owner Login ဝင်ပြီး Settings → Business Cloud Sync → ဒီ Device ၏ Firestore Activity ကို စစ်ပါ။ ကောင်တာသည် local-only estimate ဖြစ်သည်။
6. `members/000000` cleanup သည် တူညီသော Email အတွက် valid active UID Member တစ်ခု ရှိပြီးမှသာ Owner က အသုံးပြုနိုင်သည်။ အခြား Member များကို အလိုအလျောက် မဖျက်ပါ။
7. Firebase Console → Firestore → Usage ကို တကယ့် billable usage အတွက် အဓိကထားကြည့်ပါ။

ဒီ version သည် Firebase Project `minimart-production` ကို ဆက်သုံးသည်။ `store-mini` အဟောင်းကို မဖျက်ပါနှင့်။
