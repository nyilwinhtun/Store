# v3.2.4 — စတင်အသုံးပြုရန်

1. မူရင်း v3.2.3 Hotfix 5 ကို မဖျက်ပါနှင့်။ v3.2.4 ကို Folder အသစ်ထဲ Extract လုပ်ပါ။
2. VS Code တွင် v3.2.4 Folder ကို Open လုပ်ပါ။
3. Terminal တွင် `node -v` နှင့် `npm -v` စစ်ပါ။
4. Root Dependencies ကို `npm install` ဖြင့် တပ်ဆင်ပါ။
5. Firebase Functions Dependencies ကို `npm --prefix functions install` ဖြင့် တစ်ကြိမ်တပ်ဆင်ပါ။
6. Java ရှိပြီး Emulator စမ်းမည်ဆိုလျှင် `npm run qa` ကို run ပါ။
7. Java မရှိသေးပါက `npm run qa:quick` ဖြင့် TypeScript၊ Functions Build၊ Security Preflight နှင့် Website Build ကို စစ်ပါ။
8. Bundle အသေးစိတ်ကို `npm run report:bundle` ဖြင့် ကြည့်ပါ။
9. QA အားလုံးအောင်မြင်ပြီး Test Firebase / Physical Device စမ်းသပ်ပြီးမှ Production Deploy လုပ်ပါ။

## နေ့စဉ် အသုံးပြုမည့် Command

```bash
npm run dev
```

## Update မတင်မီ

```bash
npm run qa
```

Firestore Emulator အတွက် Java JDK 11 သို့မဟုတ် ပိုမြင့်သော version လိုအပ်သည်။
