# v3.2.3 Hotfix 5 — စတင်အသုံးပြုရန်

1. Hotfix 5 ZIP ကို Folder အသစ်ထဲ Extract လုပ်ပါ။ Hotfix 4 Folder ကို မဖျက်ပါနှင့်။
2. VS Code မှာ Hotfix 5 Folder ကို Open Folder ဖြင့်ဖွင့်ပါ။
3. Terminal မှာ `pwd` နှင့် `ls package.json` ဖြင့် Project Root မှန်ကြောင်း စစ်ပါ။
4. `npm install` လုပ်ပါ။
5. `npm run typecheck` လုပ်ပါ။
6. Typecheck အောင်မြင်မှ `npm run build` လုပ်ပါ။
7. Website စမ်းရန် `npm run dev` လုပ်ပါ။
8. Java ထည့်ပြီးမှ `npm run test:rules` ဖြင့် Firestore Emulator Test လုပ်ပါ။

ဒီ Hotfix က TypeScript Error သုံးခုကို ပြင်ထားတာဖြစ်ပြီး Emulator Test အောင်မြင်ကြောင်း မဆိုလိုပါ။ Rules Test အားလုံးအောင်မြင်မှသာ Firebase Rules ကို သက်ဆိုင်ရာ Test Project မှာ Deploy စမ်းသပ်ပါ။ Production သို့ မတင်သေးပါနှင့်။
