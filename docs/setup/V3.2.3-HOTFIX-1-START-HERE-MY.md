# v3.2.3 Hotfix 1 — စတင်အသုံးပြုရန်

ဒီ Hotfix သည် `functions/src/index.ts` မှာ `user is possibly 'undefined'` (`TS18048`) ဖြစ်နေသော Cloud Functions TypeScript Build Error ကို ပြင်ဆင်ထားသည်။

## 1. လက်ရှိ Project ကို Backup လုပ်ပါ

လက်ရှိ VS Code Project Folder ကို မဖျက်ပါနှင့်။ Folder တစ်ခုလုံးကို Copy လုပ်ပြီး Backup အဖြစ်ထားပါ။ Hotfix ZIP ကို Folder အသစ်ထဲ Extract လုပ်ပါ။

## 2. Cloud Functions Build

VS Code Terminal မှာ Project Root အတွင်း ရှိနေကြောင်း စစ်ပြီး အောက်ပါ Command များကို အစဉ်လိုက်လုပ်ပါ။

```bash
npm --prefix functions install
npm --prefix functions run clean
npm --prefix functions run build
```

`functions/src/index.ts` အတွက် `TS18048` error မပေါ်တော့ရပါ။

## 3. Root App Build

```bash
npm install
npm run check:security
npm run typecheck
npm run build
```

## 4. အရေးကြီးသော သတိပေးချက်

- ဒီ Hotfix သည် Source Code ပြင်ဆင်မှုသာဖြစ်သည်။ Firebase Production ကို မDeploy လုပ်ထားပါ။
- Build အောင်မြင်သည်နှင့် Blocking Functions အလိုအလျောက် အသက်ဝင်သွားမည် မဟုတ်ပါ။ Identity Platform ကို သတ်မှတ်ချက်အတိုင်း ပြင်ဆင်ပြီး Blocking Triggers ကို သီးခြား Register / Deploy လုပ်ရပါမည်။
- Emulator / Test Firebase မှာ Owner Login၊ Cashier Login၊ Unauthorized User ကို ပိတ်ခြင်း၊ Public Account Creation ပိတ်ခြင်းကို စမ်းသပ်ပြီးမှ Production သို့ တင်ပါ။
