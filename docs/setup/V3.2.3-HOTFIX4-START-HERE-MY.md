# Minimart POS v3.2.3 Hotfix 4 — စတင်အသုံးပြုရန်

1. Hotfix 4 ZIP ကို Folder အသစ်ထဲ Extract လုပ်ပါ။
2. အဲဒီ Folder ကို VS Code ဖြင့်ဖွင့်ပါ။
3. VS Code Terminal မှာ `pwd` နှင့် `ls package.json` ဖြင့် Project Root မှန်ကြောင်းစစ်ပါ။
4. `npm install` လုပ်ပါ။
5. `npm run typecheck` နှင့် `npm run build` လုပ်ပါ။
6. Java တပ်ဆင်ပြီး Firestore Emulator စတင်နိုင်ပါက `npm run test:rules` လုပ်ပါ။

မူရင်း Hotfix 3 ကို မဖျက်ပါနှင့်။ Live Firebase သို့ Rules မတင်မီ Emulator Tests အားလုံးအောင်မြင်ကြောင်း အတည်ပြုပါ။
